# PR動画（相手別・各30秒）

OP/ED 用に生成した素材クリップ（`movie/src/`）と、実機のスクリーンショット
（`store/screenshots/`）を組み合わせて、**相手ごとに言うことを変えた30秒**を
6本つくってある。全部 **1080×1920 / 30fps / H.264 / AAC**。

- X（旧Twitter）にそのまま添付できる（30秒以内）
- App Store のプレビュー動画の規定（15〜30秒・1080×1920）にも収まる
- Google Play は YouTube リンク方式なのでそのまま使える

最後の5.8秒は6本とも共通で、**「単語帳を開くより、冒険しよう。」＋ WORDRIA のロゴ**。

## 6本の中身

| ファイル | 相手 | 最初の一言 | 締めの一行 | BGM |
|---|---|---|---|---|
| `out/PR_main.mp4` | 汎用（ストア／X本命） | 「知ってる」だけでは、倒せない。 | 速く答えるほど、強くなる英単語RPG | title |
| `out/PR_toeic.mp4` | TOEIC学習者 | 600から、動かない。 | TOEIC®対策に、「速さ」という武器を。 | battle |
| `out/PR_jhs.mp4` | 中学生 | 単語帳、何回も閉じた。 | 中学英語からはじめる英単語RPG | field |
| `out/PR_hs.mp4` | 高校生・大学受験 | 読めるのに、間に合わない。 | 大学受験の語彙まで、遊びながら。 | battle2 |
| `out/PR_parent.mp4` | 保護者 | 「勉強しなさい」の、前に。 | 学習そのものに、上限は置きません。 | ending |
| `out/PR_dev.mp4` | X・AI界隈（個人開発） | 個人開発で、ここまで作れる。 | 絵・音・動画・コードまで、生成AIで。 | battle2 |

言っていることは `docs/MISSION.md` と `docs/STORE_COPY.md` に合わせてある。

- 速さ（「知ってるのに出てこない」）を軸にして、「楽しく学べる」は言わない
- **変わりうる数字（価格・1日の回数・収録語数）は画面に出していない**。
  変えても動画を作り直さなくていいようにしてある
- TOEIC® を出す回（main / toeic / hs）だけ、同じ画面に免責表記を入れている

## 作り直し

```bash
node tools/build_pr.js              # 6本ぜんぶ
node tools/build_pr.js toeic jhs    # 名前を指定して一部だけ
```

ffmpeg が要る。PATH に無ければ `FFMPEG=/path/to/ffmpeg node tools/build_pr.js`。
中間ファイルは `movie/tmp/`（gitignore 済み）。

## 直したいとき

`movie/pr.json` だけ触ればいい。スクリプトは触らなくていい。

```jsonc
{ "name": "4択クイズ", "img": "store/screenshots/02_quiz.png",
  "dur": 3.4,          // 秒
  "yoff": 0.42,        // 9:16 に切るとき、縦のどこを残すか（0=上 1=下）
  "zoom": 1.09,        // 終わりまでにどれだけ寄るか
  "text": ["制限時間内に、意味を選ぶ。"],
  "pos": "top" }       // 文字を上に出すか下に出すか
```

- 動画素材のカットは `"src"` と `"trim": [開始, 終了]`
- 文字の中で `{g}…{/}` で囲んだところが金色になる
- BGM は `"bgm": { "file": …, "start": 秒 }`。`start` は曲の頭がおとなしい時に動かす
- 効果音は `"sfx": [{ "file": …, "cut": 3, "at": 0.2 }]`（3カット目の0.2秒後）
- エンドカードの文言は `"endcard"`。`catch` が共通のキャッチコピー

尺は「各カットの長さの合計 −（カット数−1）× `crossfade`」。
いまは全部 29.8〜30.0 秒に収まっている。

## 素材の出どころ

- `movie/src/op1〜3.mp4`, `ed2〜3.mp4` … OP/ED 用に生成した10秒クリップ
  （`docs/MOVIE_PROMPTS.md`）。崩れる区間は `trim` で避けてある
  （例：ed3 の後半は文字が崩れるので前半しか使っていない）
- `store/screenshots/*.png` … 実機のスクリーンショット。ゲーム画面は
  ここからしか出していない（作り物の画面は1枚も入れていない）
- `assets/bgm/`, `assets/sfx/`, `assets/ui/logo.png` … ゲーム本体と同じもの

## 注意

- **画面を変えたらスクショを撮り直して、この動画も作り直すこと。**
  店頭の絵と中身が食い違うのは、審査以前に見た人を戸惑わせる
- 配信が始まったら、エンドカードに「App Store / Google Play で配信中」の
  一行を足せる（`pr.json` の `endcard.text` に足すだけ）
