# リスニング音声（英単語の読み上げ）実装計画

問題が出た瞬間に単語を音声で読み上げる。設定でオフにできる。
2026-08-22 時点。**声の生成以外はすべて準備済み。**

---

## 決まっていること

| | |
|---|---|
| 端末側の音声合成 | **使わない。**こちらで作った音声ファイルを同梱して再生するだけ |
| 声 | 単語ごとに男性か女性のどちらか1つ。**同じ単語はいつも同じ声** |
| 男性の声 | seed_audio の既定（サンプル承認済み・2026-08-21） |
| 女性の声 | **未決定。サンプルを作って選ぶところから** |
| 対象 | 4,883語（TOEIC 1,907 ＋ 中高 4,016 − 重複 1,040） |
| 内訳 | 女性 2,483語（50.8%）／ 男性 2,400語（49.2%） |
| 形式 | mp3 / モノラル / 24kHz / 32kbps |
| 容量 | 1語あたり平均 3.5KB → **全体で約17MB**（ビルドは 64MB → 81MB） |

**声を単語ごとに割り振るので、音声データは2倍になりません。**
割り当ては単語名のハッシュ（FNV-1a）で決めているため、作り直しても同じ結果になります。

## 生成の手順（検証済み）

1語ずつ生成すると 4,883 回になるので、**40語を1回にまとめて生成し、無音で切り分けます。**
8語で検証したところ、区切りが 1:1 で取れました。

### 1. 割り当てとバッチを作る

```bash
node tools/build_voice_list.js
# → build/voice_plan.json   単語 → { 声, ファイル名 }
# → build/voice_batches.json  123バッチ（1回40語）
```

貼り付ける文面を見るには `--show 3`。単語は `.` と空行で区切ってあります。

### 2. 生成する（Higgsfield / seed_audio）

```
mcp__Higgsfield__generate_audio  model: "seed_audio", prompt: <バッチのprompt>
```

- 1回あたり **0.4クレジット**。123回で **約50クレジット**
- 40語で 40〜50秒の音声になります

### 3. 切り分ける

```bash
node tools/split_voice.js <落としたwav> --batch f000
# → assets/voice/<単語>.mp3
```

**区切りの数が語数と合わない場合、このツールは何も書き出さずに失敗します。**
1語ずれると、以降すべての単語に別の単語の音声が付いてしまうためです。
その場合は `NOISE` / `MINSIL` を調整するか、そのバッチを分割して作り直します。

## まだやっていないこと

### ① 女性の声を決める

**ここから始めてください。** seed_audio のパラメータ（`mood` / `pitch_rate` /
`expression_intensity` など）を変えたサンプルを3〜5種類作り、同じ単語で聞き比べてもらう。
判断するのは Kazuhiro さん。

サンプルに使う単語（長さと音の種類が散るように選んである）:

```
negotiate.  discrepancy.  unfortunately.  watch.  thorough.  available.
```

### ② 再生の実装

- `assets/voice/<単語>.mp3` を、問題が出た瞬間に再生
- **BGMは止めない。**音量を下げて重ねる（BGMを切ると戦闘の緊張が切れる）
- タイトルに **「英語の音声」のオン／オフ**を追加。`localStorage` に保存
- iPhone対策：`js/bgm.js` と同じく、**最初のタップで解禁した1つの要素を使い回す**。
  声用に専用の要素を1つ持ち、`src` を差し替えて鳴らす。
  要素を単語ごとに作ると iOS では鳴りません（BGMで実際に踏んだ問題）
- 音声が無い単語（生成漏れ・熟語など）は**黙って飛ばす**。エラー音は出さない

### ③ ビルドへの組み込み

- `tools/build_www.js`：`assets/voice/` をそのままコピー（変換しない。すでに32kbps）
- `tools/build_inline_assets.js`：**プレビュー版には入れない。**
  17MB あるので 16MB のアーティファクト上限に収まりません

## 補足：なぜ端末の音声合成を使わないか

別のTOEIC学習アプリでの経験から、**端末側で合成した音声は品質が安定せず、
OSの更新で急に変わる**ため使わないと決めています。容量17MBを払ってでも、
こちらで作った同じ音声を全員に届けます。
