# 追加BGMプロンプト（第3弾・闘技場公開版のための2曲）

現在の10曲（title/field/town/dungeon/battle/battle2/battle_dungeon/midboss/boss/ending）で
ほぼ足りています。公開に向けて**あると格段に良くなるのは次の2曲だけ**です。

- アップ先: https://github.com/KazuhiroHashi/toeic_quest/upload/claude/toeic-quest-game-8zva6k/assets/bgm
- Sunoで「Instrumental」ON、60〜180秒。ファイル名は下記の通り。
- **ゲーム側は対応済み**: アップした瞬間から自動で使われます（無い間はboss.mp3等で代用）。

## 1. lastboss.mp3（真・沈黙王ミュートス専用曲）★優先

11戦目の隠しボス「真の姿」専用。今はboss.mp3の使い回しなので、
「まだ終わっていなかったのか…！」という驚きを曲でも出したい。

```
Ultimate final boss theme for a JRPG, beyond the normal boss battle: a desperate, awe-inspiring last stand. Full orchestra with dark choir chanting, cathedral pipe organ, relentless taiko and timpani, tragic soaring strings melody over menacing low brass, brief quiet eerie interlude then explosive climax, majestic and overwhelming, instrumental, seamless loop
```

## 2. victory.mp3（勝利ジングル・任意）

戦闘勝利時は今、効果音のみ。5〜8秒の短いファンファーレがあると勝った実感が増します。
（こちらは効果音寄りなのでElevenLabsでも可）

```
Short triumphant JRPG victory fanfare, bright brass flourish rising to a cheerful resolution, timpani roll and cymbal crash, 6 seconds, instrumental
```

※これ以上の追加（章別フィールド曲など）はストーリーモード本格実装の段階でOK。
