# 戦闘・UIデザイン素材の依頼リスト（GPT-image用）

「黒い枠に文字だけ」のUIを、リメイク級のデザインに引き上げるための素材リストです。
**優先度順**に並んでいます。1番のフレームだけでも見た目が激変します。

- アップ先: https://github.com/KazuhiroHashi/toeic_quest/upload/claude/toeic-quest-game-8zva6k/assets/ui
- ファイル名は【保存名】どおり。**アップした瞬間に自動適用**される仕組みを実装済みです
  （frame.png はゲーム1・新作の両方のウィンドウに即反映されます）

---

## 1.【最優先】ウィンドウフレーム（会話枠・メニュー枠の装飾）

ゲーム中の全ウィンドウ（メッセージ・コマンド・ステータス）の枠として9スライスで使います。
**中央部分は暗い半透明**であることが重要です（文字が上に乗るため）。

```
ファンタジーRPGのダイアログウィンドウのフレーム素材を1枚描いてください。
正方形。外周に金の飾り縁（コーナーに小さな装飾金具、辺は細い二重ライン）、
内側は濃紺〜黒の半透明パネル（上品なグラデーション）。
中央は模様を入れずシンプルに（文字を表示する領域のため）。
FFリメイクやHD-2Dゲームの上質なUI水準。背景透過。文字は入れない。
【保存名: frame.png】
```
