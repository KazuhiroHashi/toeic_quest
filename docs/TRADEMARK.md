## なぜ急ぐ必要があるのか

日本の商標は**先に出願した人が勝ちます**（先願主義）。早い者勝ちです。

このアプリは一度この問題に遭っています。もとの名前「WORD QUEST」に
他社の出願（商願2026-8512）が見つかり、名前を捨てました。
ロゴ・起動画面・OP/EDムービー・スクリーンショット・ストアの文章・PR動画を
すべて作り直すことになり、**まるまる一日かかりました。**

そして、名前を狙われるのは**無名のうちではなく、売れ始めたとき**です。
アプリストアを見て回って、伸びているアプリの名前を先に出願する人が実際にいます。
「売れてから出そう」と思ったときには、もう誰かが出した後、という順番になりえます。

「前から使っていたから大丈夫」（先使用権・商標法32条）は、
**「その名前が世間に広く知られていること」が条件**です。
出たばかりのアプリでは、まず認められません。守りとしては数えないでください。

## いくらかかるか

特許庁に払うお金は法律で決まっています。**値切る方法はありません。**

| | 第9類だけ（1区分） | 第9類＋第41類（2区分） |
|---|---|---|
| 出願のとき | **12,000円** | 20,600円 |
| 登録が決まったとき（10年分） | 32,900円 | 65,800円 |
| 登録料を5年分割にした場合 | 17,200円 | 34,400円 |

- **出願料の内訳**：3,400円 ＋ 8,600円 × 区分数。「3,400円」だけでは出願になりません
- **落ちた場合、登録料はかかりません。**出ていくのは 12,000円だけ
- 中小企業・個人事業主向けの**手数料の減免制度は、商標には使えません**
  （特許と実用新案だけが対象です）
- 紙で出す場合、あとから**電子化手数料**が別に請求されます（数千円）。
  正確な額は窓口で確認してください

**まずは第9類だけで十分**です。予算を抑えるならこれ一本で構いません。

## 手順1：まず無料で調べる（J-PlatPat の称呼検索）

2. 上のメニューから **「商標」→「商標検索」**
3. 検索項目のプルダウンで **「称呼（単純文字列検索）」** を選ぶ
4. 検索キーワードに **`ワードリア`** と入力（カタカナで）
5. 「検索」を押す

## 手順3：願書に書く内容（WORDRIA用）

窓口で最終確認してもらう前提の、下書きです。

### 商標そのもの

| | |
|---|---|
| 商標登録を受けようとする商標 | **WORDRIA** |
| 書き方 | **標準文字**で出願する（ロゴの絵ではなく、文字だけで押さえる） |

**なぜ標準文字か**：ロゴの絵で登録すると、そのデザインしか守れません。
文字で登録すると、**書体を変えても守られます**。ロゴは今後変わりうるので、
文字で押さえるほうが実用的です。

### 区分と指定商品

## 手順4：出し方（紙で郵送する場合）

いちばん道具が要らない方法です。パソコンの設定も要りません。

1. **願書を作る** … A4の紙に、上の内容を印刷する
   （書式は窓口でもらうか、特許庁のサイトのひな形を使う）
2. **特許印紙を買う** … **郵便局**で「特許印紙を12,000円分ください」と言う
   - ⚠️ **収入印紙ではありません。「特許印紙」です。**別物です
   - ⚠️ 小さな郵便局には置いていないことがあります。**大きめの局へ**
3. **願書に印紙を貼る**（消印は押さない。押すと無効になります）
4. **特許庁へ郵送する**

```
〒100-8915
東京都千代田区霞が関三丁目4番3号
特許庁長官　殿
```

書留など、記録の残る方法で送るのが安心です。**出願日は特許庁に届いた日**
ではなく、**発送した日**（郵便局の消印日）になります。

## そのあと何が起きるか

| 時期 | 何が起きる |
|---|---|
| 出願から数週間 | 特許庁から「出願番号」の通知が届く。**この番号は控えておく** |
| 出願から8〜12か月 | 審査結果が届く |
| 通った場合 | 「登録査定」が届く。**30日以内に登録料を払う**（払わないと権利になりません） |
| 通らなかった場合 | 「拒絶理由通知」が届く。**反論できます**。窓口に相談を |

### 審査を早めたいとき（無料）

アプリを公開して実際に使っていれば、**早期審査**を申請できます。
**追加費用はかかりません。**8〜12か月が **2〜3か月**に縮みます。

使っている証拠（ストアの画面、アプリの画面など）を出すだけです。
出願したあとに申請できるので、**出願 → 公開 → 早期審査**の順が最短です。
