# TOEIC QUEST 画像ガイド（ChatGPTで絵を作る手順）

このゲームの敵イラスト(PNG)を、ChatGPT(Plus)の画像機能で作るための手順書です。
生成した画像は**このチャットでClaudeに送るだけ**でゲームに組み込まれます。

---

## ステップ

1. ChatGPTを開き、下の【共通スタイル】を**最初に1回だけ**送って世界観を固定する
2. 続けて【各キャラのプロンプト】を1体ずつ送る
3. 出てきた画像を保存（iPhoneなら長押し→"画像を保存"）
4. その画像を **Claude（このチャット）に送る**。ファイル名は不要、私が正しい名前で保存します
5. 気に入らなければ「もっと可愛く」「色を暖かく」等の一言で作り直しでOK

> 画像は **正方形 / 背景は透明か単色 / キャラ1体だけ** が理想です。プロンプトにその指定を入れてあります。

---

## 【共通スタイル】※最初に1回だけ送る

```
これから、スマホ用RPG「TOEIC QUEST」のモンスター画像を何体か作ります。
すべて同じ絵柄で統一してください。スタイルは以下で固定します:

- かわいい2頭身のマスコットモンスター。大きな瞳、丸いフォルム、親しみやすい表情
- 手描き感のある、やわらかいセルアニメ塗り。太めの主線。パステル＋鮮やかなアクセント
- 「勉強・英単語」の世界観（本、ペン、アルファベットなどのモチーフを少し取り入れる）
- キャラは1体だけを中央に、全身。正方形（1:1）。背景は透明（透過PNG）
- 怖すぎず、不気味すぎず。子供〜大人まで好かれるポップさ
了解したら「OK」とだけ返してください。次から1体ずつ指定します。
```

## 技術メモ（Claude用）

- 保存先: `assets/enemies/<id>.png`（例 `assets/enemies/slime.png`）
- 戦闘画面は `js/battle.js` の `setEnemyArt()` が同名PNGを自動検出。無ければ絵文字にフォールバック
- 単体HTML(`dist/`)やArtifactでは外部PNGを読めないため、配布版に絵を焼き込む場合はビルド時にbase64インライン化する（今後対応）
