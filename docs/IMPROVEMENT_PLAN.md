# TOEIC QUEST 改良計画書 〜人気アプリに仕上げるために〜

「画像がひどい・音楽がない」の解消と、ゲームとしての面白さの底上げ、著作権の安全確保をまとめた計画。

## ⭐ 品質基準（2026-07-12 改訂）

- **目標水準: 2020年代の商用ゲーム（Switchで売っていておかしくないレベル）。レトロ再現は目標ではない**
- 参照するのは「ゲームの進み方」だけ。見た目・音・名前は一切参照しない
- **内製で水準に届かない部分は、必ず外部の最高水準の生成サービスを使う**:
  - 画像 → gpt-image系（ChatGPT）: 敵・背景・タイトル・顔グラ・フィールド用テクスチャ
  - BGM → **Suno Pro**（商用権利あり・FF級オーケストラ可）
  - 効果音 → **ElevenLabs Sound Effects**（有料プランで商用可・48kHz）
  - 手順は `docs/AUDIO_GUIDE.md` / `docs/ART_PROMPTS_SCENES.md`
- Claude（私）の担当は**コード・UI・統合・品質管理**に限定。自作チップチューンは廃止済み
- フィールド画面は「AI生成の描き込まれた地形テクスチャ＋小物スプライトをコードで合成描画」方式で刷新する（タイル絵の内製はしない）。それでも水準に届かない場合は「一枚絵ワールドマップ＋地点移動」方式へ切り替える

## 2. 音楽計画

- **現状**: オリジナル作曲チップチューン(実装済み)。権利関係が完全にクリーン。レトロゲーの雰囲気にも合う
- **より本格的な曲にしたい場合**(あなたが仲介できる選択肢):
  1. **フリーBGMサイト**(DOVA-SYNDROME、魔王魂 等): 高品質・商用可。ただし**各曲のライセンス確認とクレジット表記が必要**。mp3をassets/bgm/に置けば差し替えられる構造にする
  2. **AI作曲(Suno等)**: 有料プランなら商用利用可。プロンプトは私が用意可能
- 効果音は現状のWebAudio生成で十分(必要なら同様に差し替え可能)

## 3. 面白さの底上げ(次の候補・優先順)

1. **フィールド描画の高品質化**(私・コード)— 見た目の印象を大きく左右する残り最後の大物
2. **顔グラ付き会話**(画像+私)— 物語への没入感
3. **クエストログ**「つぎは南の塔へ」表示 — 迷子防止(離脱の最大要因)
4. **実績/称号**(「100問正解」「ノーミス討伐」)— コレクション欲
5. **ボス戦ギミック**(魔王第2形態: HP半分で出題が2択→高速化 等)
6. **復習ボス**「まちがえた単語だけで挑む記憶の神殿」— 学習効果の柱

## 4. 命名ポリシー(今後の基準)

- ✅ 良い: 誰でも読めて意味が伝わる(ハーブティー、ワードウーズ、エナジーコーヒー)
- ✅ 良い: 一般名詞の組合せ・ラテン系の造語(レクトス、ヴォキャブロス)
- ❌ 避ける: 既存ゲーム固有の名前(やくそう、キメラのつばさ、メラ等)
- ❌ 避ける: 無理な駄洒落・不自然な省略(イレイザーだけ 等) → 修正済み

## 5. 著作権・商標チェックリスト(重要)

| リスク | 対応 |
|---|---|
| **⚠️「TOEIC」は ETS の登録商標** | **アプリ名に使うとApp Store審査却下や権利者からの申立てのリスクが高い**。リリース時はアプリ名を変更する(例:「英単語クエスト」「ワードクエスト」等)。説明文での「TOEIC®対策に」という**記述的使用**は一般に行われているが、名称・アイコンには使わない。ゲーム内の「TOEIC400レベル」表記も「Lv.400」等に置換できる設計にしておく |
| 既存ゲームの固有名詞・呪文名・UI文言 | 使用しない(命名ポリシー通り。「ぼうけんのしょ」等は置換済み) |
| 既存ゲームの**メロディ** | BGMは完全オリジナル作曲。既存曲の耳コピ・アレンジは絶対にしない |
| AI生成画像 | プロンプトに「〜風」「(特定作品/会社名)のスタイルで」を**入れない**(現行プロンプトはクリーン)。既存キャラに酷似した出力が出たら使わず再生成 |
| フォント | システムフォントのみ使用(ライセンス問題なし) |
| フリー素材を使う場合 | 曲ごとのライセンス確認+クレジット表記をREADMEとアプリ内に記載 |
