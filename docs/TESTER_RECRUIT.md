# テスター募集：コピペして押すだけキット

知り合いがいなくても大丈夫。**知らない人に募集するのが正解**（忖度のない反応が取れる）。
ここにある文章は**全部コピペでそのまま使えます**。URLの部分だけ差し替えてください。

---

## 0. まず用意するもの（1回だけ）
- **X（旧Twitter）のアカウント**（既存でも新規でもOK。新規なら名前は `Bridge AI` / `WORD QUEST開発中` など）
- **Google グループ**（Androidテスター用のメール受け皿。作り方は下の「B-1」）
- **TestFlightの公開リンク**（Apple承認後）／**Google クローズドテストのオプトインURL**

# B. Android：Google クローズドテスト（12人×14日）

## B-1. Googleグループを作る（テスターの受け皿。3分）
1. https://groups.google.com → 「グループを作成」
2. 名前 `wordquest-testers` ／ メール `wordquest-testers@googlegroups.com`
3. **参加設定を「誰でも参加できる」**にする ← ここ重要
4. Play Console のテスター欄には**このグループのメールアドレス1つだけ**を登録すればOK
   （＝以後、参加者が増えてもConsole側の作業は不要）

## B-2. Play Console 側（5分）
1. Play Console → テスト → **クローズドテスト** → トラック作成 → AABアップロード
2. テスター → 「メーリングリスト」→ `wordquest-testers@googlegroups.com` を追加
3. 「テストへのリンクをコピー」→ このURLを配る

## B-3. 12人が足りない時（相互協力・実際に機能する場所）
どこも「お互いのアプリのテスターになる」文化です。**参加＝リンクを押すだけ**なので相手の負担も軽い。
- **Reddit**: `r/AndroidClosedTesting` / `r/TestMyApp`（英語。「12 testers needed, I'll join yours too」で通じる）
- **X**: `#クローズドテスト` `#テスター募集` で検索して相互依頼
- 有料代行（数千円）もあるが、まず上記2つで足ります

### 相互依頼の英文（コピペ）
```
Hi! I need 12 testers for my Google Play closed test (14 days).
It's a JRPG for learning English vocabulary — just install and it counts.
I'll join your test too — drop your link and I'll opt in right away!
My link: （テストリンク）
```

## B-4. テスターにお願いする文（コピペ・LINEなどで）
```
アプリのテストにご協力お願いします🙏
下のリンクを開いて「テスターになる」→ インストールするだけでOKです。
（起動しなくても大丈夫です。14日間アンインストールしないでいてくれると助かります）
（テストリンク）
```

# C. iOS：TestFlight（審査なしで配布）

## C-1. 公開リンクの作り方
1. App Store Connect → 対象App → **TestFlight** タブ
2. 「グループを追加」→ 名前 `パブリックベータ`
3. ビルドを選択 → **「公開リンクを有効にする」**（人数上限も設定可：例100人）
4. 出てきたURLをXやLINEで配る ← **メールアドレス収集不要**

## C-2. 配布文（コピペ）
```
テスト版を配布中です！
iPhoneの方はこちらから遊べます👇
（TestFlightリンク）

※TestFlightという無料アプリが入ります（Apple公式のベータ配布アプリ）
※感想・不具合はTestFlight内の「フィードバックを送信」からどうぞ
```

---

# D. 反応をどう読むか（G1ゲートの判定）
- **TestFlight → App Store Connect → TestFlight → 指標** で、インストール数／**セッション数**が見える
- 見るべきは1つ：**「インストールしただけの人」と「2回以上遊んだ人」の比率**
  - 2回以上遊んだ人が **3割以上** → コアが面白い証拠。次のフェーズへ
  - ほぼ全員1回で終わり → **どこで飽きたか**を聞く（＝改善の最大ヒント）
