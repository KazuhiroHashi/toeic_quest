**WORD QUEST → WORDRIA（ワードリア）** に改名した。

理由は商標。J-PlatPat で「WORD QUEST」に他社の商願2026-8512が出ていることが
分かったため、登録される前に名前を離した。「WORDRIA」は同日の検索で0件だった。

| | 扱い | なぜ |
|---|---|---|
| ストアのApp名・説明文・ロゴ・ゲーム内表示 | **WORDRIAに変える** | 商標を避けるのが目的 |
| バンドルID `com.bridgeai.wordquest` | **変えない** | 変えると別アプリ扱い。既存のApp記録・レビュー・売上がすべて切れる。IDは利用者から見えない |

### 「遊び方」の3文目を消した（2026-09-19）

前の版はこうだった。

    正解すれば、選んだコマンドが発動します。
    間違えると、不発に終わります。そのあいだにも敵は攻撃してきます。

- **「不発に終わる」は計画や交渉に使う言い回し**で、ゲームの動作には硬い。
  直前の「発動します」と語も重なる。「何も起きません」にした
- **「そのあいだにも敵は攻撃してきます」は消した。** 同じ場面の説明が3文続き、
  3文目は RPG なら当たり前のこと。「メカニクスの細部は書かない。遊べば分かる」
  という方針にも反していた
- **間違えたときの行を、丸ごと消した。** 一度「間違えると、何も起きません。」に
  書き換えたが、これも没。外れたときの話は要らない。

  消してみると、空行で対句にしていたのが邪魔だったと分かった。
  「選ぶ → 答える → 発動する」を3行続けると、手順として一息で読める。
  対になる文を置こうとしたこと自体が間違いだった

書かなかったこと：
- 「覚えることと勝ち進むことが同じ行為」のような、遊びの構造の説明。
  読んで意味が取りにくく、遊べば分かること
- オフライン対応・アカウント不要。事実だが、書かないと減点される類の話ではない
- 改名したこと。旧名を知らない新規の利用者にとっては雑音でしかない
- メカニクスの細部（ダメージ計算、速度ボーナス等）。遊べば分かる

### 今後の変更時も守る方針

- 読者を否定する前提の呼びかけを使わない（例：「単語帳が続かなかった人へ」）
- 「単語を知っているだけでは勝てません」のような、学習意欲を削ぐ表現は使わない。
  単語を覚えたくて入れるアプリに対して逆効果
- コマンド名を列挙しない。「その場面に合う」のような説明的な修飾も入れない
- **「単語帳より速く、楽しく」を売り文句にしない**（2026-09-19 本人の判断で変更）

  引き継ぎ書の方針は「『単語帳より圧倒的に速く、楽しく覚えられる』を前面に出す」
  だった。それに沿って3行目に「単語帳をめくるより、ずっと速く、ずっと楽しく。」
  と書いていたが、外した。理由は2つ。

  1. **1行目と同じことを言い直しているだけ。** 「単語帳を開くより、冒険しよう。」
     で既に言っている
  2. **「速い」に根拠がない。** 数値を書かない方針なのに、形容詞なら許される
     というのは筋が通らない

  言いたいことは2行目の「夢中で戦っているうちに単語が頭に入る」が担っている。
  そこに仕組みが書いてあり、速さの主張より強い。

  ついでに「3倍速」のような数値も書かない。根拠がないと嘘になり、審査でも指摘される
- 「遊び方」の欄に説教めいたメッセージを入れない

- **データを収集または共有していますか？** → はい（広告SDK AdMob 経由）
- **収集/共有するデータの種類**：
  - **デバイスまたはその他のID（広告ID）** … 収集＝はい／共有＝はい／目的＝**広告またはマーケティング**（不正防止も）。アカウント用途ではない。
  - **アプリのアクティビティ（アプリ内操作）** … AdMobが広告最適化に利用する範囲で「収集」。
  - ※位置情報・氏名・メール等は収集しない（アカウントなし）。
- **転送時の暗号化** → はい
- **データ削除のリクエスト手段** → アカウント無し。データは端末内のみ。**アンインストールで削除**（その旨を記載）。

### ★ TOEIC という語について

| App名 | **入れない** | ガイドライン5.2.1（知的財産）の差し戻しはApp名に集中する。名前を直すと再提出で数日 |

## サイト側でやること（bridge-ai-tokyo.com）

**提出より先にやること。** コード側のURLは `/wordria/` に書き換え済みなので、
サーバにファイルが無いとリンク切れになり、審査で差し戻される。

1. `https://bridge-ai-tokyo.com/wordria/privacy.html` を置く（中身は `store/privacy.html`）
2. `https://bridge-ai-tokyo.com/wordria/terms.html` を置く（中身は既存 `/wordquest/terms.html` と同じでよい）
3. 旧 `/wordquest/` は**消さない**。そのまま残すか、`/wordria/` へのリダイレクトにする
4. App Store Connect の「App情報」で、プライバシーポリシーURLと利用規約URLを `/wordria/` に変える

置いたあと、必ずブラウザで両方のURLを開いて表示されることを確かめる。

急がなくてよいもの：
- AdMob管理画面のアプリ表示名を WORDRIA に変える（IDは触らない）

## Xcode 側でやること（`npx cap sync` では変わらない）

`capacitor.config.json` の `appName` を WORDRIA にしてあるが、
**ホーム画面に出るアプリ名はこれでは変わらない。** Info.plist の
`CFBundleDisplayName` が別に持っているため。Mac で以下をやること。

1. Xcode で `ios/App/App.xcworkspace` を開く
2. 左のツリーで `App` → `App` → **Info.plist**
3. `Bundle display name`（CFBundleDisplayName）を **`WORDRIA`** に書き換える
   （項目が無ければ `+` で `Bundle display name` を追加する）
4. `Bundle name`（CFBundleName）も `WORDRIA` にしておく

**`Bundle Identifier` は触らないこと。** `com.bridgeai.wordquest` のまま。
ここを変えると別アプリ扱いになり、App記録も購読も切れる。

確認：ビルドして実機に入れ、ホーム画面のアイコンの下が「WORDRIA」になっていればよい。
