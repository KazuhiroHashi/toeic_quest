# WORD WIZ 〜英単語と精霊のカードバトル〜 設計書

黒猫のウィズ型「クイズ×カードバトルRPG」のTOEIC版。2作目。
1作目(TOEIC QUEST)と同じ語彙データ3000語を使用。

## 0. 参考研究: 黒猫のウィズはなぜ面白いか

| 要素 | 黒猫のウィズ | 本作への写像 |
|---|---|---|
| デッキ | 精霊カード5枚。属性(火水雷光闇)、AS(正解時自動発動)、SS(溜めて任意発動) | 同構造をそのまま採用 |
| パネル選択 | 1〜3色パネル。色が多い=難問だが攻撃参加が増えクリ率UP | **色数=単語レベルの高さ**。TOEIC900パネルは3色で全員攻撃+クリ率大 |
| 属性相性 | 3すくみ(1.5倍/0.5倍)、光闇相互 | 火→雷→水→火、光⇔闇 |
| チェイン | 連続正解で蓄積しダメージ増、誤答でリセット | 同じ。学習の連続正解を火力に直結 |
| 敵カウント | 数ターンごとに敵攻撃 | 同じ。「あと何問で倒す」の緊張感 |
| 育成 | 強化合成・進化(絵が変わる)・潜在能力 | マナで強化、進化石で進化(絵・ステ強化) |
| 収集 | ガチャ・図鑑・書き込まれた可愛いカード絵 | ゲーム内ジェムのガチャ+図鑑。絵はSVG生成(リリース時にイラスト差替) |
| 継続 | ストーリー・イベント・トーナメント | 章=TOEICレベル帯。デイリー要素は将来 |

面白さの本質: **「難しい問題に挑む勇気」がそのまま火力になる**リスクリターン設計と、
クイズの腕(知識)とデッキ構築(戦略)の2軸で強くなれること。

## 1. ゲーム概要

- 舞台: 言葉を食う影「ヴォイド」に侵食された魔法図書館レキシカ。司書見習いが精霊カードと共に書架を浄化する。
- 章 = TOEICレベル(400〜900)。章ごとに4クエスト(3ウェーブ+ボス)。
- 戦闘フロー:
  1. 3枚の出題パネルから1枚選ぶ(属性色1〜3 + 単語レベル表示)
  2. 4択クイズ(5秒)。速答グレード: ≤2秒 Excellent ×1.3 / ≤3.5秒 Great ×1.15 / Good
  3. 正解 → パネル色と同属性のカードが攻撃(飛翔エフェクト+ダメージポップ)
  4. チェイン+1(誤答で0)。ダメージ = ATK × 属性(1.5/1/0.5) × グレード × (1+チェイン×5%) × クリ(2倍)
  5. 正解ごとに各カードのSSゲージ+1。満タンでタップ発動(大ダメージ/回復/タイマー延長/出題レベルダウン等)
  6. ターン終了で敵カウント-1。0で敵攻撃 → チームHP減
- パネル設計: 1色=章レベル-100の単語 / 2色=章レベル / 3色=章レベル+100(全カード攻撃・クリ率+25%)

## 2. カード(精霊) 23種

- 属性: 火🔥 水💧 雷⚡ 光✨ 闇🌙
- レアリティ ★1〜★5。最大Lv = 20+★×10。進化(★3以上)で絵にオーラ・ステ1.3倍・Lv上限+10
- AS例: 速答強化(2秒以内×1.4) / チェイン強化(5以上で×1.5) / 弱点特効 / 正解時回復 / クリ率+10%
- SS例: 単体大ダメージ / 全体攻撃 / 回復30% / 次3問タイマー+3秒 / 次3問レベルダウン / チェイン+5 / 敵攻撃80%軽減 / 全員攻撃×1.8
- 学習支援スキル(タイマー延長・レベルダウン)を「戦略」に組み込むのが本作の独自性

## 3. 育成・経済

- クエスト報酬: マナ(強化通貨)+カードEXP+初回クリアジェム
- 強化: マナ消費でレベルUP(即時、素材合成なし=学習アプリ向けに簡略化)
- 進化: 最大Lv+進化石(ボス初回ドロップ)
- ガチャ: ジェム100/回。★2 55% / ★3 30% / ★4 12% / ★5 3%
- 収益化(リリース時): ジェム購入IAP+広告除去。学習中に広告を出さない方針は1作目と同じ

## 4. 画面・技術

- 画面: タイトル → ホーム(クエスト/編成/強化/ガチャ/ずかん) → バトル → リザルト
- 見た目: ダークネイビー+属性グラデ+ガラス質カードフレーム。攻撃オーブ飛翔、ダメージポップ、チェインバッジ、SSカットイン、クリティカルフラッシュ
- カード絵: SVGプロシージャル生成(丸くて目の大きいマスコット精霊、属性配色、レアリティ装飾)。リリース時に本物のイラストへ差替可能なパス
- 実装: `wiz/` 配下。語彙は `../data/vocab_*.js` を流用。保存はlocalStorage
