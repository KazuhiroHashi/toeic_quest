# WORDRIA ストア文面（速さを軸にした改稿版）

`docs/MISSION.md` の方針（点を分けるのは語彙量ではなく、意味が出てくる速さ）を
先頭に置いた版。App Store Connect にそのまま貼れる形にしてある。

ゲーム側ブランチの `docs/STORE_LISTING.md` にある制約はすべて踏襲した。

- App名に `TOEIC` を入れない。サブタイトル・説明文では `TOEIC®` を使い、免責表記を同じ画面に出す
- 変わりうる数字（金額・1日の回数・広告の間隔・収録語数）は書かない
- 物語（四天王・ラスボス）とパーティ編成には触れない。遊ぶ前の人に意味が伝わらないため
- サブスクの名称・月額・自動更新・解約方法はアプリ内購入画面（`party/js/pstore.js`）が満たす

## 1. サブタイトル（30字）

**推奨（28字）— 1語だけ差し替え**

```
TOEIC®・大学受験・中学高校英語 速答コマンドバトル
```

現行は `TOEIC®・大学受験・中学高校英語 爽快コマンドバトル`。
**「爽快」→「速答」の1語だけ**を変える。検索語（TOEIC® / 大学受験 / 中学高校英語 /
コマンドバトル）は全部残るのでASOへの影響がなく、方針だけが入る。

「爽快」はどのゲームでも言える語で、このアプリを説明していない。
「速答」は他の英単語アプリが言えない語なので、ここに置く価値がある。

## 2. 説明文（本文）

そのまま貼る。約760字／上限4000。

```
その単語、「知ってる」だけで止まっていませんか。

試験で点が伸びないのは、単語を知らないからではありません。
知っているのに、意味が出てくるまでが遅いからです。

WORDRIA（ワードリア）は、その「速さ」を鍛える英単語RPGです。

画面に出た英単語の意味を、4つの選択肢から選びます。
正解すると敵に攻撃が入り、速く答えるほど強い一撃になります。
迷っているあいだに時間が切れると、こちらがダメージを受けます。

3秒考えて思い出せる単語は、本番では使えません。
このゲームで戦えるようになった単語が、試験で使える単語です。

■ 出題される範囲を選べます
中学1年から高校3年まで、学年を選ぶとその範囲の単語が中心に出ます。
大学受験の語彙でも、TOEIC®テスト頻出レベルの語彙でも遊べます。

■ 耳からも覚えられます
すべての単語に読み上げ音声がついています。

■ 「知っているつもり」が見えます
覚えた単語が「即答・曖昧・苦手」の3つに分かれて見えます。
いちばん危ないのは、知らない単語ではなく「曖昧」な単語です。
日ごとの正答率の推移と、間違えた回数の多い単語は、プレミアムで表示されます。

無料で遊べます。アプリ内に広告が表示されます。
プレミアム（自動更新サブスクリプション）に登録すると、広告が表示されなくなり、
学習の記録をすべて見られます。

利用規約 https://bridge-ai-tokyo.com/wordria/terms.html
プライバシーポリシー https://bridge-ai-tokyo.com/wordria/privacy.html

※本アプリはETSおよびTOEIC®プログラムとは一切関係ありません。「TOEIC」はEducational Testing Service（ETS）の登録商標です。
```

## 5. 想定される反論と、返し方

> 「速さより語彙量のほうが大事では？」

**語彙量より速さが大事、とは言っていない。** 語彙量は前提で、その上で点を分けるのが速さ。
この順番で答えれば矛盾しない。実際、出題範囲は中学から TOEIC® 帯まで用意してあり、
語彙量を増やすこと自体はこのアプリの機能に含まれている。

**根拠として言えること**: TOEIC L&R のリーディングは75分で100問。
共通テストの英語も語数が多く時間が厳しい。これらの試験は構造上、
「知っているか」だけでなく「制限時間内に処理できるか」を測っている。

## 適用のしかた

この文面は最終的に App Store Connect と Google Play Console に直接貼る。
リポジトリ側に反映するなら、ゲーム側ブランチの `docs/STORE_LISTING.md` の
「説明文」「プロモーションテキスト」「サブタイトル」の各節を差し替える。

説明文の変更はアプリの審査を伴う。プロモーションテキストとスクリーンショットの
文字は審査なしで差し替えられるので、**先にそちらで反応を見てから説明文を変える**のが安全。
