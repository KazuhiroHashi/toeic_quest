### ⚠️ マイナンバーカードは出さない

裏面にマイナンバーが印刷されている。番号の提供先は法令で限られており、
Apple に出すのは適切でない。**運転免許証の表・裏（カラー）**を使う。

### ⚠️ ②③は法人向けの書類

9/9 にサポートがしてくれたのは「**個人事業主での登録**」の手続きだった。
個人事業主なら**③の登記事項証明書は存在しない**（法人の登記簿なので）。

- **法人なら** … ③は法務局で取得（オンライン約500円・窓口600円・即日）。
  ②は代表者自身が在籍証明書を作り、代表者印を押す
- **個人事業主なら** … ③は用意できない。**先に金子さんへ返信して事情を伝える。**
  代わりに出せるのは、税務署の収受印がある開業届の控え／納税証明書／印鑑登録証明書

**黙って別の書類を出すより、一言返信するほうが早い。**

### ⚠️ 完了するまで iOS は出せない

移行の処理中は「Certificates, Identifiers & Profiles」が使えない。
つまり**配布用の証明書が作れず、Xcode の Archive → Upload が最後で落ちる**。

Xcode で出るのはこの2つ。**どちらもアプリの不具合ではない。**

```
No Account for Team "W2TSCP2QY2".
No signing certificate "iOS Distribution" found
```

この間、**Android（Google Play）はまったく影響を受けない**。そちらを進める。

### 方針：組織への移行を完了させる（取り消しはしない）

**移行申請を取り消して個人アカウントに戻す、という選択肢は採らない**（本人の判断・2026-09-10）。
組織としての登録を前提に進める。App Store の販売元名を BRIDGE AI にすることが目的で、
そこを諦めるなら最初から申請していない。

したがってサポートへは「**完了させてほしい**」の一本で依頼する。
あわせて次の2点を必ず聞く。放っておくと、また何週間も止まる。

```
　1. 移行完了の見込み時期
　2. こちらで追加で提出すべき書類・情報があれば、その内容
```

返事が来なければ**3営業日**で催促する。前回は8月17日に申請して、
返事が来るまで**23日**かかった。

電話が要ると言われた場合、対応できるのは**平日 12:15〜12:45**（090-9112-3814）。

### この間、iOSは出せない。Androidを進める

移行が終わるまで証明書が作れないので、iOSは手が出せない。
**Android（Google Play）はまったく影響を受けない**ので、そちらを先に出す。

## 完了したあとにやること

1. **Xcode でアカウントを入れ直す**
   Xcode → Settings → Apple Accounts。「Certificates, Identifiers, & Profiles」の
   赤い ❌ が消えていることを確認する。
2. **配布用の証明書を作る**
   同じ画面の Manage… → ＋ → **Apple Distribution**
3. **プロジェクトで Team を選び直す**
   Signing & Capabilities → Automatically manage signing にチェック → Team を選ぶ
4. **Archive → Distribute App → App Store Connect → Upload**

> 移行で **Team ID が変わる可能性がある**。変わっていたら、上の1〜3を
> やり直せば追いつく。バンドルID（`com.bridgeai.wordquest`）は変わらない。

## 完了すると変わること

| | 変化 |
|---|---|
| App Store の販売元名 | 個人名 → **BRIDGE AI** |
| 個人メンバーシップの「売上とトレンド」 | 使えなくなる（Appleの事前案内どおり） |
| 移行前の売上 | 移行開始時点の銀行口座に振り込まれる |
| バンドルID・アプリの記録 | **変わらない** |
