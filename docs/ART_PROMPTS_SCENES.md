# 戦闘背景10枚+タイトル画 コピペ用プロンプト集

敵と同じ要領です。**新しいChatGPT会話**で、まず【背景の共通スタイル】を1回貼ってから各プロンプトを順に。
アップロード先(背景): **https://github.com/KazuhiroHashi/toeic_quest/upload/claude/toeic-quest-game-8zva6k/assets/bg**
アップロード先(タイトル画のみ): **https://github.com/KazuhiroHashi/toeic_quest/upload/claude/toeic-quest-game-8zva6k/assets/ui**

背景は置くだけで戦闘画面に自動適用されます(敵の絵の後ろに表示)。

## 進捗チェック
- [ ] zone1〜zone6(フィールド戦闘の背景)
- [ ] cave / tower1 / tower2 / maou(ダンジョン戦闘の背景)
- [ ] title(タイトル画面・uiフォルダへ)

## 【背景の共通スタイル】※最初に1回だけ貼る
```
これから、スマホRPGの戦闘背景画像を作ります。すべて同じ絵柄で統一してください。
やわらかい手描き風のファンタジー風景画。明るく彩度高め、アニメ背景のようなタッチ。
キャラクターや文字は一切入れない。横長ではなく正方形(1:1)。画面下半分は敵が立つ「地面」がはっきり見える構図。
了解したら「OK」とだけ返してください。次から1枚ずつ指定します。
```
