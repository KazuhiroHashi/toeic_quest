# 四天王4人＋真ラスボス 専用イラスト生成ガイド（GPT-image用）

今は四天王＝将軍/死神/魔法使いの絵を流用中。専用イラストに差し替えるための5枚です。
各四天王は「封印した力（聞く・話す・読む・書く）」がデザインモチーフ。

- アップ先: https://github.com/KazuhiroHashi/toeic_quest/upload/claude/toeic-quest-game-8zva6k/assets/enemies
- **既存ファイルとは別の新しい名前**にしてあります（今の絵を壊しません）。
  5枚が揃ったら、こちらでボスに割り当てて再ビルドします。緑の「Commit changes」を忘れずに。

## 共通の作り（各プロンプトに入っています）

既存の敵イラストと画風を揃えるため:「手描き風の油彩タッチ、明るく鮮やかな色、
くっきりした輪郭、背景は完全に透過、キャラクター1体だけを中央に大きく、
文字・ロゴなし、2DファンタジーRPGのボスイラスト。かっこよく威圧感があるが、
気持ち悪すぎない親しみも残す」。

## 補足

- **割り当て予定**: king_howl→第6戦ハウル / king_gag→第7戦ガグ / king_blank→第8戦ブランク /
  king_erase→第9戦イレイズ / maou_mutos→第10戦ミュートス(第一形態) / maou_true→最終戦(真ラスボス)。
- キャラの一貫性を出すには、四天王4体を**同じ会話の中で続けて**生成し
  「同じ画風・同じシリーズの四天王で」と伝えると揃いやすいです。ミュートスの2枚も
  「第一形態→覚醒後の真の姿」として同じ会話で作ると対比が出ます。
