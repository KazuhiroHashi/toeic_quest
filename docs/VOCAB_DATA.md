# 単語データ（中学・高校/大学受験）

**現時点でゲームには接続していません。**データとして保持しているだけです。
接続方法（どのモードで、どう出題するか）は後で設計します。

## 調査した「必要語彙数」の根拠
| 区分 | 必要語数 | 出典の要旨 |
|---|---|---|
| 中学（学習指導要領） | **1,600〜1,800語** | 旧課程1,200語から増加 |
| 高校（学習指導要領） | **1,800〜2,500語** | 旧課程1,800語から増加 |
| 中高合計 | 約3,600〜4,300語 | 高校卒業までに学ぶ総量 |
| 大学入学共通テスト | **4,000〜5,000語** | 共通テスト突破の目安 |
| 難関私大 | 6,000〜7,000語 | さらに上乗せが必要 |

> 当初案の「中学1,000語・高校2,000語」では**中学が明確に不足**だったため、指導要領準拠の規模に作り直しました。

## 作成したデータ

### `data/vocab_jhs.js` — 中学 1,845語
```js
window.VOCAB_JHS.basic     // 923語  中1〜中2中心（基礎語・曜日・月・数など含む）
window.VOCAB_JHS.advanced  // 922語  中2〜中3・高校入試レベル
window.VOCAB_JHS.all       // 1845語 結合済み（出題プール用）
```

### `data/vocab_hs.js` — 高校 2,171語
```js
window.VOCAB_HS.standard   // 1182語 共通テスト基礎〜標準
window.VOCAB_HS.advanced   // 772語  難関大レベル
window.VOCAB_HS.idiom      // 217語  入試頻出熟語（look forward to など）
window.VOCAB_HS.all        // 2171語 結合済み
```

**合計 4,016語**（中学1,845＋高校2,171）＝ 共通テストの目安4,000〜5,000語に対して **89%充足**。
難関大を狙う場合は、高校advancedに1,000語ほど追加する余地があります（後日拡張可）。

## データ形式
既存の `window.VOCAB[400]` 等と**完全に同じ形式**なので、そのまま `QUIZ.ask()` に流せます。
```js
{w:"negotiate", m:"交渉する", p:"v"}
```
品詞タグ: `v`動詞 / `n`名詞 / `adj`形容詞 / `adv`副詞 / `phr`熟語 / `prep`前置詞 / `conj`接続詞 / `pron`代名詞

## 品質保証（自動検証済み）
- **重複ゼロ**：中学↔高校間、ファイル内ともに重複なし（高校側は中学収録語を自動除外）
- **不正データゼロ**：意味が英語のまま／空欄／記号のみのエントリは検出して除外
- 品詞分布：名詞1,715 / 動詞1,090 / 形容詞815 / 熟語217 / 副詞112 / その他67

## メンテナンス方法
元データは `tools/vocabsrc/*.txt`（`単語|意味|品詞` の1行1語形式）。
編集後、下記でJSを再生成します（重複除去・検証・統計出力まで自動）。
```bash
node tools/build_vocab.js
```
| ソースファイル | 内容 |
|---|---|
| `jhs1.txt` | 中学 基礎 |
| `jhs2.txt` | 中学 発展・入試 |
| `hs1.txt` | 高校 標準（共通テスト） |
| `hs2.txt` | 高校 難関 |
| `phrase.txt` | 入試頻出熟語 |
