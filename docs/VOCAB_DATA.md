**現時点でゲームには接続していません。**データとして保持しているだけです。

## 想定するプロダクト構成（入り口を分ける）
プレイヤー層が違うため、**入り口（アプリ or モード選択）を分離**する方針。
TOEIC語彙と学生向け語彙が一部重複するのは**問題なし**（別の入り口＝別の学習者が使うため）。

| 入り口 | 対象 | 使う単語データ |
|---|---|---|
| **社会人向け（TOEIC）** | 20〜40代・自己研鑽 | `VOCAB[400〜900]`（既存） |
| **中学生向け** | 中1〜中3・高校受験 | `VOCAB_JHS.g1 / g2 / g3` |
| **高校生向け** | 大学受験 | `VOCAB_HS.lv1 / lv2 / lv3` |

## 調査した「必要語彙数」の根拠
| 区分 | 必要語数 |
|---|---|
| 中学（学習指導要領） | **1,600〜1,800語**（旧課程1,200語から増加）|
| 高校（学習指導要領） | **1,800〜2,500語** |
| 大学入学共通テスト | **4,000〜5,000語**（中高合計）|
| 難関私大 | 6,000〜7,000語 |

> 当初案の「中学1,000語」では不足のため、指導要領準拠の規模に作り直し済み。

## `data/vocab_jhs.js` — 中学 1,845語（**学年別**）
```js
window.VOCAB_JHS.g1   // 600語  中1（be動詞期の基礎語・曜日・月・数・身の回り）
window.VOCAB_JHS.g2   // 600語  中2（動詞の活用が増える時期・日常語の拡張）
window.VOCAB_JHS.g3   // 645語  中3・高校入試（抽象語・社会的テーマ語）
window.VOCAB_JHS.all  // 1,845語 結合
```
**学年配分の考え方**：教科書の必修語（`G1_CORE`）を中1に固定し、抽象度の高い入試頻出語（`G3_HINT`）を中3へ。残りを中2に置き、実際の教科書配分（中1が最も多く前倒し）に合わせて均衡化。

## `data/vocab_hs.js` — 高校/大学入試 2,171語（**難易度3段階**）
```js
window.VOCAB_HS.lv1   // 700語  共通テスト基礎（+基本熟語）
window.VOCAB_HS.lv2   // 699語  共通テスト〜中堅私大（+入試熟語）
window.VOCAB_HS.lv3   // 772語  難関大（abolish, ambiguous, unprecedented 等）
window.VOCAB_HS.all   // 2,171語 結合
```
**入試頻出熟語217語**（`look forward to` / `take advantage of` 等）は lv1・lv2 に配分済み。

**合計 4,016語**（中学1,845＋高校2,171）＝ 共通テスト目安4,000〜5,000語に対し**89%充足**。
難関大まで完全カバーするには lv3 にあと1,000語ほど追加の余地あり（後日拡張可）。

## データ形式
既存 `window.VOCAB[400]` と**完全同一**なので、そのまま `QUIZ.ask()` に流せます。
```js
{w:"negotiate", m:"交渉する", p:"v"}
```
品詞: `v`動詞 / `n`名詞 / `adj`形容詞 / `adv`副詞 / `phr`熟語 / `prep`前置詞 / `conj`接続詞 / `pron`代名詞

## 品質保証（自動検証済み）
- **重複ゼロ**：学年間・レベル間・中学↔高校間すべて（高校側は中学収録語を自動除外）
- **不正データゼロ**：意味が英語のまま／空欄／記号のみのエントリは検出・除外
- 総語数 4,016（検証時点）

## メンテナンス方法
元データ `tools/vocabsrc/*.txt`（`単語|意味|品詞`）を編集し、再生成：
```bash
node tools/split_vocab.js    # 学年別・レベル別に分割して data/*.js を生成
```
| ソース | 内容 |
|---|---|
| `jhs1.txt` / `jhs2.txt` | 中学（基礎／発展）→ g1・g2・g3 へ自動振り分け |
| `hs1.txt` | 高校 標準 → lv1・lv2 |
| `hs2.txt` | 高校 難関 → lv3 |
| `phrase.txt` | 入試頻出熟語 → lv1・lv2 |

学年やレベルの振り分けを変えたい場合は、`tools/split_vocab.js` 内の
`G1_CORE`（中1必修）/ `G3_HINT`（中3・入試）の語リストを編集します。

## 既存TOEIC語彙との関係
- 既存 `vocab_400〜900.js` は3,000エントリ・**実ユニーク1,907語**（レベル間で重複あり）
- 高校データとの重なりは約24%。**入り口が別なので重複は許容**（方針どおり）
