# TOEIC QUEST 設計書

ドラクエ1風レトロRPG × TOEIC英単語学習アプリ
「戦闘 = 英単語クイズ」で、遊んでいるうちに語彙力が上がるゲーム。

- 対象プラットフォーム: iPhone (App Store) ※HTML5で実装し Capacitor でネイティブ化
- 収益化: 無料 + 広告 / 課金(買い切り or サブスク)で広告除去
- リポジトリ: https://github.com/KazuhiroHashi/toeic_quest

---

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| 一言で | 「英単語に5秒以内に答えることが攻撃になる」ドラクエ風RPG |
| ターゲット | TOEIC 400〜900 を目指す社会人・学生。ドラクエ世代(30〜50代)と相性が良い |
| 学習の核 | 制限時間5秒 → 「見た瞬間に意味が分かる」即答力を鍛える(TOEICのスピード対策そのもの) |
| ゲームの核 | レベルアップ・装備・宝箱・ボス討伐という王道RPGの報酬ループ |
| 参考にした学習×ゲーム | Duolingo(ストリーク/失敗ペナルティ)、モンスターストライク型の周回報酬、Anki(間違えた単語の再出題) |

### 学習とゲームの融合ポイント
1. **攻撃=単語クイズ**: 正解→攻撃ヒット / 不正解・時間切れ→空振り+敵の反撃。学習行為そのものが戦闘リスクと直結。
2. **速答ボーナス**: 2秒以内の正解は「かいしんのいちげき」(ダメージ2倍)。瞬発力を強く報酬化。
3. **敵レベル=単語レベル**: 強い敵ほど高レベル(TOEIC900)の単語。ゲーム進行=学習レベル進行。
4. **魔法=上位レベルへの挑戦**: 「ファイア６００」「サンダー８００」など魔法名に数字。MPを消費し、そのレベルの単語に正解しないと発動失敗。今の自分の敵より上のレベルに任意で挑戦する仕組み。
5. **苦手単語の再出題(Anki風)**: 間違えた単語は出題重みが上がり、正解を重ねると重みが戻る。メニューの「たんごちょう」で復習可能。

## 2. ストーリー

> レキシア大陸では、かつて誰もが英語を話せた。
> しかし魔王ヴォキャブロスが大陸の《言葉の力》を奪い、人々は言葉を忘れ、魔物が言葉を支配した。
> ラーニング王の命を受けた勇者は、単語の力で魔物を打ち倒し、
> 二人の将軍(リーディング将軍レクトス/リスニング将軍ヒアロス)を退け、
> 「ことばのカギ」で魔王城の扉を開き、魔王をTOEIC900の語彙で打ち倒す。

進行フラグ:
1. 王様から使命を受ける(チュートリアル)
2. 洞窟のレクトス討伐(ハイライトセイバー入手ルート)
3. 塔のヒアロス討伐 → **ことばのカギ** 入手
4. 魔王城の扉をカギで開け、魔王ヴォキャブロス討伐 → エンディング

## 4. 戦闘・クイズ仕様

### 4.1 クイズ
| 項目 | 仕様 |
|---|---|
| 出題形式 | 英単語を表示 → 日本語の意味を4択から選ぶ |
| 制限時間 | **5秒**(タイマーバー表示)。時間切れ=不正解 |
| 敵特性「hasty」 | タイマーが3.5秒に短縮される敵(タイムイーター等) |
| 出題レベル | 通常攻撃=敵のレベル(400〜900) / 魔法=魔法名の数字レベル |
| 誤答選択肢 | 同レベル帯・同品詞の単語の意味からランダム3つ(意味の重複なし) |
| 出題の重み | 苦手単語(誤答履歴あり)は出題確率アップ。正解2回で通常に戻る |

### 4.2 戦闘フロー(ターン制)
```
敵出現 → [コマンド選択]
 たたかう → クイズ(敵Lv) → 正解: ダメージ(2秒以内なら会心2倍)
                          → 不正解/時間切れ: 空振り → 敵の攻撃
 じゅもん → MP消費 → クイズ(魔法Lv) → 正解: 発動 / 不正解: 不発(MPは消費)
 どうぐ   → ハーブティー等を使用
 にげる   → 成功率 ~55%(ボスは不可)
敵HP0 → 経験値+ゴールド → レベルアップ判定(呪文習得)
自HP0 → 「あなたは しんでしまった」→ 城で復活・所持金半分(DQ準拠)
```

### 4.3 ダメージ計算
```
プレイヤー攻撃: max(1, atk − enemyDef/2 + rand(0..4))   atk = str + 武器atk
会心(2秒以内): 上記 × 2(防御を無視しないが2倍)
敵の攻撃:      max(1, enemyAtk/2 − def/4 + rand(0..3))  def = vit + 防具def
魔法攻撃:      power ± 15%(敵防御無視) / 回復: power固定
```

### 4.4 敵の特性
| 特性 | 効果 |
|---|---|
| double | 30%で2回攻撃 |
| heal | HP30%以下のとき自己回復 |
| fire | 炎ブレス(防具軽減が半減する強攻撃) |
| hasty | クイズ制限時間を3.5秒に短縮 |
| flee | 高確率で逃げる(メタルワード: 倒すと経験値500) |
| boss | 逃走不可・イベント戦 |

## 5. 成長システム

- レベル1〜30。必要経験値 `7 × (lv−1)^2.35`(序盤サクサク、後半しっかり)
- 上昇: HP +7.5/Lv、MP +4.5/Lv(Lv3から)、ちから +2.6/Lv、みのまもり +2.0/Lv
- 呪文習得(魔法名の数字=出題される単語レベル):

| Lv | 呪文 | MP | 効果 |
|---|---|---|---|
| 4 | ヒール５００ | 4 | HP35回復 |
| 7 | ファイア６００ | 5 | 敵に28前後 |
| 10 | リターン | 8 | 城へ帰還(フィールド用) |
| 13 | ヒールラ７００ | 8 | HP90回復 |
| 16 | サンダー８００ | 10 | 敵に65前後 |
| 20 | メテオ９００ | 15 | 敵に120前後 |

- 装備: 武器6種(えんぴつ→でんせつのペン)、防具6種(Ｔシャツ→でんせつのローブ)。最強装備は魔王城の宝箱。
- 道具: ハーブティー(HP回復) / きかんチケット(帰還) / しゅうちゅうコーヒー(MP回復) / ことばのカギ(イベント)

## 6. ワールド・敵配置

- フィールド: 40×36タイル。城からの距離で6ゾーンに難度が上がる(川と橋・山脈で誘導)
- ゾーン1〜6 = TOEIC 400/500/600/700/800/900 の敵テーブル
- 施設: レキシア城(拠点・復活地点)、スタディの村、ミドルタウン、ハイスコアの街(宿屋・店の品揃えが段階的に強化)
- ダンジョン: リーディングの洞窟(暗闇・ボス:レクトス)、リスニングの塔(2F・ボス:ヒアロス)、魔王城(最強装備の宝箱・魔王)
- 敵: **32種**(雑魚29 + ボス3)。詳細は `data/enemies.js` 参照

## 7. データ設計

すべて静的JS(ビルド不要・オフライン動作)。将来はJSON+サーバ配信に移行可能。

```
data/vocab_400.js … vocab_900.js   // 各500語 計3000語 【生成済み・検証済み】
  window.VOCAB[400] = [ {w:"purchase", m:"購入する", p:"v"}, ... ]
  w=英単語, m=日本語の意味(4択の選択肢になる), p=品詞(n/v/adj/adv/phr)

data/enemies.js
  ENEMIES(32種), ZONE_TABLE(ゾーン別出現テーブル・重み付き),
  LEVEL_TABLE(Lv1-30), SPELLS, WEAPONS, ARMORS, ITEM_DEFS

data/maps.js
  MAPS.world/castle/town1-3/cave/tower1-2/maou
  タイル文字列 + events(NPC/宝箱/ボス/移動/施錠扉)
```

### セーブデータ(localStorage → iOS版は Capacitor Preferences)

## 8. 技術アーキテクチャ

```
[今回のプロトタイプ]                    [App Store リリース時]
HTML5 + Canvas + 素のJS(ビルド不要)  →  Capacitor でラップ → Xcode → App Store
  index.html                              + AdMob プラグイン(広告)
  css/style.css                           + StoreKit / RevenueCat(課金)
  js/quiz.js    出題・タイマー・苦手管理    + Capacitor Preferences(セーブ)
  js/battle.js  戦闘ロジック               + Game Center(実績・ランキング)※任意
  js/game.js    フィールド・イベント・UI
  data/*.js     単語・敵・マップ
```

- ブラウザでそのまま動作(GitHub Pagesでテスト配信可能)→ 実機確認が容易
- 描画: Canvas 2D。タイルは手続き描画、敵・NPCは絵文字ベース(プロトタイプ)。リリース時にドット絵アセットへ差し替え可能な構造
- 効果音: Web Audio APIで生成(ファイル不要)

## 9. 収益化設計

| 手段 | 内容 | 実装 |
|---|---|---|
| バナー広告 | 画面最下部に常設(プロトタイプはプレースホルダ枠実装済み) | AdMob Banner |
| インタースティシャル | 「宿屋に泊まる」「ゲームオーバー」のタイミングで低頻度表示(戦闘中は出さない) | AdMob Interstitial |
| リワード広告 | 「動画を見て全回復」「動画を見て経験値1.5倍(30分)」 | AdMob Rewarded |
| プレミアム(広告除去) | 買い切り ¥480〜¥980 目安。全広告非表示+リワード特典は無条件化 | StoreKit2 / RevenueCat |

方針: 学習の邪魔をしない(クイズ中・戦闘中に広告を出さない)。広告が出るのは「休憩の区切り」だけ。

### 継続率を上げる将来機能(人気学習アプリの定石)
- デイリークエスト(「今日20問正解でボーナスゴールド」)
- ストリーク(連続ログイン日数で称号)
- 週間スコアランキング(Game Center)
- プッシュ通知(「復習の時間です」)
