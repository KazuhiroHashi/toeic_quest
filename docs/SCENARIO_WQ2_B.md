## 0. テーマの背骨(一本)

**「ことばは ひとを きずつける。それでも つたえることには あたいがある。」**

- 沈黙王ミュートスは「ことばの加害性」の象徴。彼の主張は一度は正しく聞こえるように書く。
- 仲間4人は全員「ことばに傷つけられた側」であり同時に「ことばで誰かを傷つけた側」。
- 各章は仲間一人の「声/ことばを巡る喪失と再生」の物語として完結し、同時に本筋の伏線を積む。
- 戦闘で唱える「いにしえのことば(=英単語)」は、この世界では「まだ誰も傷つけたことのない、
  生まれたてのことば」という設定。だから魔を祓う力を持つ。

### 物語の三幕

| 幕 | 章 | 感情の機能 |
|---|---|---|
| 一幕 | 1〜3章 | 喪失の提示。ガイとリナの傷と再生 |
| 二幕 | 4〜5章 | **中盤の大転換点: ミアの正体発覚と離脱**。ユウの傷の開示 |
| 三幕 | 終章 | **ツイスト: ミュートスの正体=誰よりことばを愛し、ことばに殺された歌い手オルフェ**。カタルシス |

### 沈黙王ミュートス(ツイストの核・厳重ネタバレ)

- 正体は12年前まで王都にいた**旅の歌い手オルフェ**。ミアの実父。
- 妻は薬師**セレナ**(ミアの母)。疫病の年、「薬師が毒を撒いた」という**根も葉もない噂(=ことば)**が
  王都に広がり、民の声に押された王バルドは追放の布告に署名。セレナは失意のうちに獄で病死した。
- オルフェは歌で無実を訴え続けたが、群衆の罵声にかき消された。**誰よりことばを愛した男が、
  ことばに全てを奪われた。** 彼は無音の塔で「沈黙の魔導書」を見出し、自らの声を最初の捧げ物として
  ミュートスとなった。
- 彼は声を「破壊」していない。**奪った声はすべて無音の塔の「こえの繭」に大切に保管している。**
  「ことばさえなければ、誰も傷つかず、誰も傷つけない。私は世界を救っている」——それが彼の動機。
- 幼い娘ミアは神殿に預けられ、彼は娘の記憶からも自分を消した。**娘にだけは、父がことばを
  憎む化け物になったと知られたくなかった。**

### その他

- **バルド王**: グロッサ現王。12年前、民の声に負けて布告に署名した張本人。悔恨を抱える。
- **ソラ**(10歳): ガイの妹。声を奪われて以来、筆談と木の笛で話す。
- **フィオ**: リナの元親友。声を奪われた今も、身振りと石板で子どもたちに魔法を教えている。
- **セレナ**: 故人。ミアに読めない手紙を遺した。

# 5. 演出・実装メモ(シナリオ側からの要求)

1. **ミュートスの「文字で話す」演出**: 終章のミュートスのセリフは全てウィンドウ枠なしの
   光る文字テキストで表示(通常会話と視覚的に区別)。声を取り戻す一瞬だけ通常の会話枠になる——
   この枠の切り替え自体が演出。

3. **こえの繭の間**: BGMを消し、環境音(寝息のような声)のみにする。本作唯一の無音BGMマップ。

   (2択・どちらでも正解だが返答が変化)にして、プレイヤー自身に「ことばを選ばせる」。
5. **エンディングのユウの演説**: テキスト送りをあえて遅くし、「つっかえる」間を再現する。
6. **サブイベント報酬**: 数値報酬は控えめにし、専用メッセージ・専用演出を主報酬とする
   (感情軸シナリオの一貫性のため)。
