# AdMob：押すだけ手順（15分）

やることは「アカウント作る → アプリを2つ登録（iOS/Android）→ 各1つ広告ユニット作る → **4つのIDをコピーして渡す**」だけ。
**支払い情報は後回しでOK**（お金が発生してから設定すれば足ります）。

---

## STEP 1：アカウント作成（3分）
1. https://admob.google.com/ を開く
2. 右上「ご利用開始」→ **Play Consoleと同じGoogleアカウント**でログイン
3. 国＝**日本** ／ タイムゾーン＝**日本** ／ 通貨＝**JPY** を選ぶ
   - ⚠️ **通貨は後から変更できません**。必ずJPYに。
4. 利用規約に同意 → 「AdMobアカウントを作成」

---

## STEP 2：アプリを登録（Android用・3分）
1. 左メニュー **「アプリ」→「アプリを追加」**
2. プラットフォーム＝ **Android**
3. 「アプリはApp StoreまたはGoogle Playに登録されていますか？」→ **「いいえ」**
4. アプリ名 `WORDRIA` → 「追加」
   （※すでに `WORD QUEST` の名前で登録済み。IDが同じなら影響しないので急いで直さなくてよい）
5. 出てくる **アプリID（`ca-app-pub-XXXXXXXX~YYYYYYYY` ← チルダ〜）をメモ**

## STEP 3：広告ユニットを作る（Android用・2分）
1. そのアプリの画面で **「広告ユニット」→「広告ユニットを追加」**
2. 形式は **「リワード」** を選択　← ★ここ重要（バナーでもインタースティシャルでもない）
3. 広告ユニット名 `continue_reward`
4. 報酬の設定：報酬の量 `1` ／ 報酬アイテム `continue`（何でもOK）
5. 「作成」→ 出てくる **広告ユニットID（`ca-app-pub-XXXXXXXX/ZZZZZZZZ` ← スラッシュ /）をメモ**

---

## STEP 4：iOS用にもう一度（STEP 2〜3を繰り返し・5分）
- 「アプリを追加」→ プラットフォーム＝ **iOS** → ストア未登録＝「いいえ」→ 名前 `WORDRIA`
  （※登録済みのものは `WORD QUEST` のまま）
- 同じく **リワード** 広告ユニット `continue_reward` を作成
- **iOS用のアプリIDと広告ユニットIDもメモ**

---

## STEP 5：4つのIDを私に渡す（コピペするだけ）
下のテンプレを埋めて、そのままチャットに貼ってください。私が即コードに組み込みます。

```
Android アプリID: ca-app-pub-________~________
Android リワードID: ca-app-pub-________/________
iOS アプリID: ca-app-pub-________~________
iOS リワードID: ca-app-pub-________/________
```

---

## 注意（BAN防止・重要）
- **自分のアプリの広告を自分でタップしない**（テスト中は必ずテスト広告。コード側で `testing:true` にしてあるので、あなたが触る分には安全です）
- 本番リリース直前に、私が `testing:false` へ切り替えます

## よくある詰まり
- **「アプリを追加」が見つからない** → 左メニューが折りたたまれています。左上のハンバーガー（三本線）を押す
- **通貨を間違えた** → 変更不可なので、新しいAdMobアカウント（別Googleアカウント）を作る必要があります。作成時に必ずJPY確認
- **収益の受け取り** → 一定額（約$100相当）に到達してから、AdMob側で住所確認とお支払い方法の設定を求められます。その時でOK
