### 暴力、血液、または流血を伴う画像 → **はい**

- ☑ 人間に対する暴力または暴力の暗示

- ☐ 暴力行為は示されないものの、不安感を与える、または流血を伴う画像
- ☐ 暴力行為と直接関係のない血液

**なぜ「人間に対する暴力」も付けたか。** 質問文に「これには、プレイヤーの
キャラクターに向けられた暴力が含まれます」とある。仲間4人（リナ・ガイ・
ミア・ユウ）は人間の姿で、敵から攻撃を受ける。被弾すると枠が赤く光り
（`hitflash`）、HPが0になると「◯◯ は たおれてしまった！」と出る。
血も傷も出ないが「暴力の暗示」には当たる。

**なぜ「人間以外」も付けたか。** 敵はモンスター（アルファベットひよこ、
カンニングゴースト、四天王ハウルほか）で、こちらから攻撃する。

## ⑥ データ セーフティ

### 前提：このアプリが実際に扱っているもの

**端末の中だけに保存**（外に出ない）

| キー | 中身 |
|---|---|
| `wq2_records_v1` | 学習の記録 |
| `wq2_streak` | 連続プレイ日数 |
| `wq2_easy` | 難易度 |
| `tq_bgm` | BGM のオン／オフ |
| `tq_premium` | プレミアムの状態（キャッシュ） |
| `wq2_ads_v1` | 広告の診断ログ（利用者には見せない） |

**解析ツールは一つも入っていない。** Firebase / Analytics / Crashlytics /
Sentry いずれも無し。自前のサーバーも無い。

**外に出るのは AdMob と Google Play 課金の経由だけ。**

> 広告は `nonPersonalized: true`＝**非パーソナライズ広告**で運用している
> （`party/js/pnative.js`）。追跡はしない。だから目的の「カスタマイズ」には
> チェックを入れない。Apple への申告も「追跡しない」で統一してある。

### 入力した内容

**データを収集または共有しますか → はい**

自前では集めていないが、**アプリに組み込んだ SDK が集めるものも
「アプリが集めている」と数える**のが Google のルール。

| 質問 | 答え |
|---|---|
| 転送時に暗号化されますか | **はい**（AdMob も Play 課金も HTTPS） |
| アカウントの作成方法 | **ユーザーによるアカウントの作成を許可していない** |
| アプリ外のアカウントでログインできるか | **いいえ** |
| データ削除をリクエストする方法（任意） | **いいえ**（そもそも預かっていない） |
| 独自のセキュリティ審査バッジ | **付けない**（監査を受けていない） |

### 申告したデータの種類（4つ）

Google の公式説明「Google Mobile Ads SDK は IP アドレス・ユーザーの操作・
診断情報・デバイス識別子を自動的に収集／共有する（目的は広告・分析・
不正防止）」に対応させたもの。

| 項目 | 収集／共有 | 一時処理 | 必須か | 目的 |
|---|---|---|---|---|
| 位置情報 → **おおよその現在地** | 両方 | いいえ | 必須 | 広告／不正防止 |
| デバイスまたはその他の ID → **デバイスまたはその他の ID** | 両方 | いいえ | 必須 | 広告／分析／不正防止 |
| アプリのアクティビティ → **アプリのインタラクション数** | 両方 | いいえ | 必須 | 広告／分析／不正防止 |
| アプリの情報、パフォーマンス → **診断情報** | 両方 | いいえ | 必須 | 分析／不正防止 |

「アプリの機能」「デベロッパー コミュニケーション」「**カスタマイズ**」
「アカウント管理」は4項目とも**チェックなし**。

**「一時的に処理しますか」を「いいえ」にした理由。** 「一時的」とはメモリに
だけ置いてその場で捨てる意味。AdMob は表示回数の制限や不正検知に使うので
その場限りではない。「はい」にすると過小申告になる。

**「必須」にした理由。** アプリの中に広告をオフにする設定が無い。
AdMob の初期化は起動時に必ず走る（プレミアム加入者でも走り、表示だけ止める）。

**申告しなかったもの：** 個人情報／財務情報（購入履歴を含む）／健康／
メッセージ／写真と動画／音声ファイル／ファイル／カレンダー／連絡先／
ウェブ閲覧履歴。**月額課金は Google Play の画面で完結し、購入情報を
自前で保存していない**ので財務情報には当たらない。

### AAB のアップロード（Mac 作業）

`docs/CAPACITOR8_MIGRATION.md` の手順どおり。要点だけ：

```bash
cd ~/toeic_quest
git pull origin claude/toeic-quest-game-8zva6k
rm -rf node_modules android ios
npm install
npm run build:www
npx cap add android
npm run assets
npm run cap:sync      # ← npx cap sync で代用しないこと
```

入らず、広告が一切出なくなる**。

署名鍵（`.jks`）はこれまでのものを使う。**作り直さないこと。**
