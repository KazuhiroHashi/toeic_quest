# 新作設計書: WORD QUEST II（仮）〜沈黙の四天王〜

DQ3/4リメイクをイメージした**パーティ制**英単語RPG。TOEIC QUEST（1作目）は現状のまま保存し、
`party/` フォルダで別ゲームとして開発する。アセット（敵32体・フィールド画像30枚・BGM・SFX・単語3000語）は全て流用。

## 1作目の反省（このゲームの設計原理）

- **戦闘にバリエーションがない** → パーティ4人×役割×敵グループ×属性×フェーズ制で「毎ターン考えることがある」戦闘に
- **中ボスがあっさり** → 中ボス（四天王）は**5分超の死闘**を仕様として明記。フェーズ変化・大技の予兆と防御・回復管理が必須になるHP/火力設計
- **マップが狭い** → ワールド96×80（現行の約5倍）、塔・ダンジョンは**複数フロア構成でクリア20分**規模

# A. シナリオ（DQ4型の章仕立て）

章ごとに仲間が1人ずつ加わる構成（DQ4オムニバスの手法）。各章で新しい役割（職業）を1人ずつ
チュートリアルできるので、パーティ制の学習コストを分散できる。

## 世界観

舞台は1作目の大陸の東にある**グロッサリア大陸**。
魔王ヴォキャブロスが勇者に敗れて数年。大陸に「**沈黙王ミュートス**」が現れ、人々から**声**を奪い始めた。
ミュートスに仕える**四天王**は、ことばの四つの力「聞く・話す・読む・書く」をそれぞれ封印している
（＝英語4技能がモチーフ。倒すたびに世界に力が戻る）。

## 登場人物（パーティ4人・全員オリジナル名）

| 名前 | 職業 | 戦闘での役割 | 出題レベルの特徴 |
|---|---|---|---|
| ユウ | ゆうしゃ | バランス型・全体の主人公 | 敵と同レベル |
| ガイ | せんし | 高火力・高HPの前衛 | 敵より1段やさしい単語（速答で会心が狙いやすい） |
| リナ | まほうつかい | 攻撃呪文・全体攻撃 | 敵より1段むずかしい単語（高リスク高リターン） |
| ミア | そうりょ | 回復・補助 | 敵と同レベル（ミスすると回復できない緊張感） |

## 章立て

- **1章 旅立ち**: 声を失っていく王都グロッサ。ユウが王命を受け出発。チュートリアルダンジョン（洞窟・小規模）
- **2章 鋼の村**: 声を奪われた妹を守る剣士ガイが仲間に。四天王その一「**轟嵐のハウル**（聞くの封印者）」を音の塔で撃破 → 大陸に「聞く力」が戻る
- **3章 魔法学院**: 呪文が唱えられなくなった学院。首席リナが仲間に。四天王その二「**黙谷のガグ**（話すの封印者）」を沈黙の峡谷で撃破
- **4章 古文書の神殿**: 文字が読めなくなる呪い。巫女ミアが仲間に。四天王その三「**白紙のブランク**（読むの封印者）」を忘却の大図書館で撃破
- **5章 集結**: 4人が揃い船を入手、大陸全域が開放。四天王その四「**消筆のイレイズ**（書くの封印者）」を封印の大灯台で撃破
- **終章 沈黙王**: 天空へ続く「無音の塔」（最大ダンジョン）を踏破し、沈黙王ミュートスと最終決戦。倒すと大陸に声が戻るエンディング

## ボス格の敵アート（流用マッピング）

四天王は既存ボス絵を流用して開始（後で専用絵に差し替え可能）:
ハウル=gen_r、ガグ=gen_l、ブランク=reaper、イレイズ=wizard、ミュートス=maou、中ボス級にdragon/kraken/phoenixを配置。

# B. パーティ制バトルシステム

## 基本形（DQ3/4リメイク準拠）

- 敵は**グループ出現**（1〜3体、ボスは単体または取り巻き付き）。一人称視点（敵の絵のみ表示、パーティはステータス枠）
- 毎ターン: 生存メンバー全員のコマンドを選択（こうげき／じゅもん／ぼうぎょ／どうぐ）→ 素早さ順に敵味方の行動を解決
- **攻撃・呪文の発動には単語クイズ**（1作目と同じ4択5秒、役割ごとに出題レベルが違う＝上表）
- 正解=発動、2秒以内=会心（通常攻撃のみ）、ミス=不発＋**チェイン断絶**

## 戦闘に変化をつける新要素

1. **パーティチェイン**: ターン内で味方が連続正解するたびダメージ+15%（×1.15→×1.30→×1.45…）。
   誰かがミスすると0に戻る。「ミアの回復の前にガイが外すと痛い」など順番の駆け引きが生まれる
2. **役割別の出題レベル**（上表）: 誰で攻めるか＝どの難易度の単語に挑むか、が毎ターンの選択になる
3. **属性と弱点**: 既存のWEAKテーブルを拡張。弱点呪文は×1.5＋「じゃくてん！」演出
4. **全体攻撃**: リナの上位呪文は敵グループ全体に命中（そのぶん難しい単語）
5. **ぼうぎょ**: 被ダメージ半減。ボスの大技の「予兆」ターンに全員防御するかどうかの判断
6. **ボスのフェーズ制**（死闘の核）:
   - HP66%で**フェーズ2**: 行動が2回になる・攻撃パターン変化
   - HP33%で**フェーズ3**: 怒り状態＋**大技チャージ**（「〜は ちからを ためている！」の次ターンに全体大ダメージ。
     防御 or 速攻で怯ませる、の2択を迫る）
   - フェーズ移行時にメッセージ・画面演出・（あれば）BGM変化
7. **ボス戦時間の設計値**: ボスHP ≒ パーティの理論DPT（1ターン合計火力）×9〜12ターン。
   1ターン≒クイズ3〜4問＋メッセージ≒30〜40秒 → **戦闘時間5〜7分**の死闘になる計算

## 呪文・特技体系（DQ2〜3級の物量・全38種 / 2026-07-19拡充）

（第1段=キャラ基準レベル、第2段=+100、第3段=+200、上限900）— 強さと学習難度が連動する。

### 「どの呪文を使うか」のゲームプレイ想定（死に呪文を作らない）

| 場面 | 正解の選択肢 | 駆け引き |
|---|---|---|
| ザコ3体 | リナのグループ呪文で1ターン圧殺 | MP消費 vs ダンジョン残り時間（MP経済） |
| 硬い敵(ゴーレム系) | アーマーブレイク→物理チェイン | 1ターン投資する価値の判断 |
| 危険なザコ(全体攻撃持ち) | スリープ/サイレンスで無力化→各個撃破 | 妨害は「難単語でなく手数を減らす」節約プレイ |
| アンデッド地帯(神殿章) | ミアのホーリーがアタッカー化 | 回復役の攻撃参加でチェインが伸びる |
| ボス開幕 | ガードアップ/マジックシールド/スロウを積む | 火力を我慢してバフに回すターン配分 |
| ボス大技チャージ | 全員ぼうぎょ or ガイのかばう＋回復温存 | 予兆読み |
| ボス最終フェーズ | 力ため+チェイン×コメットのバースト | 高難度単語を連続正解できるかの腕試し |
| 消耗した帰り道 | リペルの巻物(道具)/エスケープ/リターン | 探索継続か帰還かの資源判断 |
| 暗闇ダンジョン | ライトの巻物(道具)で視界拡大 | 道具枠の管理 |

- 属性は炎/氷/雷/聖の4系統。**地方ごとに弱点分布を偏らせる**（雪地方=炎が通る、砂漠=氷、機械系=雷、
  神殿=聖）ことで「この章はこの呪文」という使い分けの理由を作る
- 敵側も同体系の呪文を使う（サイレンスで封じる価値が生まれる）

## 成長・経済

- レベルは個人別（経験値は全員に等分）。職業ごとの成長曲線・習得呪文（上表）
- そうびは1作目の文具モチーフを拡張（メンバー別装備）
- ダンジョン20分に耐えるMP・アイテム経済（キャンプ回復ポイント、中間セーブ石）

## 表記ルール（2026-07-19変更）

ゲーム内テキストは**普通の漢字かな交じり文**で書く（意図的なひらがな縛りは廃止）。
小学校高学年〜大人が自然に読める表記。固有名詞のカタカナ・漢字はそのまま使う。

# C. マップ規模・ボリューム（クリアまで約10時間）

**総プレイ時間10時間**をコンテンツ予算として設計する（2026-07-19 ユーザー指示で拡大）。

| コンテンツ | 数 | 1つあたり | 小計 |
|---|---|---|---|
| メインダンジョン（章ボスへの道） | 6 | 25分 | 2.5h |
| サブダンジョン（鍵・寄り道・隠しボス） | 4 | 20分 | 1.3h |
| 町・城（会話・買い物・イベント） | 8＋隠れ里 | 15分 | 2.2h |
| サイドクエスト | 10 | 10分 | 1.7h |
| ワールド移動・エンカウント・レベル上げ | - | - | 1.5h |
| ボス戦（四天王4＋中ボス＋最終戦） | 8 | 6-8分 | 0.9h |
| **合計** | | | **約10h** |

- **ワールド**: 96×80タイル。大陸を4地方＋中央海。章進行で船・関所開放（DQ3の世界解放感）
- **町**: 8つ＋隠れ里（王都・鋼の村・学院都市・神殿町・港町・砂漠のオアシス・雪の集落・解放後の里）。
  各町 NPC 8人以上、**封印中/解放後の2バージョン会話**、名物NPC・キャラ個別の続き物ストーリー
  （通うたびに進む「定点観測」型の小さな物語を各町に1本）
- **ダンジョン**: メイン6＋サブ4の計10。**3〜5フロア（各36〜40四方）**、
  スイッチ・カギ・ショートカット開通・宝箱8個以上・中間回復石 → **1つ20〜25分**規模
- **キャラクター個別ストーリー**: 仲間4人それぞれに章をまたぐ個人アーク（出会い→掘り下げイベント→
  決着サブクエスト）。加入章以外でも台詞が変わり続けること
- 描画エンジン・フィールド画像は1作目の実装をそのまま流用（`assets/field/`）
