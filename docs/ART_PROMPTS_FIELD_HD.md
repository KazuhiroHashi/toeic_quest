# フィールド画像 品質向上リテイク（FFピクセルリマスター級・GPT-image用）

現行のフィールド画像を「**16bit風の描き込まれたピクセルアート**」で作り直すためのプロンプト集です。
狙いは DQ1〜3リメイク／FFピクセルリマスター級の、くっきり読みやすく密度のあるタイルです。

- **ファイル名は今と同じ**。生成 → 同名でアップ → **自動で差し替わります**（コード変更不要）
- アップ先: https://github.com/KazuhiroHashi/toeic_quest/upload/claude/toeic-quest-game-8zva6k/assets/field
  （10枚前後ずつ・緑の「Commit changes」を忘れずに）
- ゲーム側も改良済み: 表示を12×10マスに拡大（1マスが大きく描画される）、地形の境界に陰影、
  海岸線の白波アニメ、キャラ足元に影 — 新画像が入るとさらに映えます

## 補足

- キャラクター（hero_*/npc_*）と宝箱は今の絵のままでも馴染みますが、統一感を極めるなら
  同じ「16bitドット絵」指定でリテイク可能です（ファイル名は同じ）。まず地形とプロップの
  差し替え結果を見てから判断で良いと思います
- 生成物がドット絵にならず「普通のイラスト」になった場合は、
  「もっと粗いドット絵に。1ドットがはっきり見えるくらい」と追加指示すると寄ります
