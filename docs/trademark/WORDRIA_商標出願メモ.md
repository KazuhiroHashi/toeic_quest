# WORDRIA／ワードリア 商標出願メモ

作成日: 2026-09-19

対象: 語彙学習RPGアプリ「ワードリア（WORDRIA）」／iOS・Android アプリ、オンライン提供

---

## 0. 先に読む（この文書の使い方）

指定商品・役務の文言は、特許庁の**「類似商品・役務審査基準」に載っている表示**をそのまま使うのが鉄則です。
理由は3つ:

1. 審査がスムーズ（商標法6条1項・2項の拒絶理由が出にくい）
2. **早期審査の対象(3)** の条件が「審査基準に掲載されている商品・役務のみを指定していること」だから
3. 区分の選び間違いによる補正・追納が発生しない

**下の文言は、出願前に必ず J-PlatPat の「商品・役務名検索」で1件ずつ照合してください。**
照合手順は §5 に書きました。完全一致でヒットすれば審査基準の表示です。

## 1. 何を出願するか（商標の態様）

| 優先 | 商標 | 形式 | 備考 |
|---|---|---|---|
| ◎ | ワードリア | 標準文字 | まずこれ。ロゴを変えても効き続ける |
| ○ | WORDRIA | 標準文字 | 別出願＝もう1件分の費用 |
| △ | WORDRIA／ワードリア（二段併記） | 標準文字 | 1件で両方をある程度カバーする折衷案 |
| △ | ロゴ（図形商標） | 図形 | デザインを守りたい場合。文字商標とは別枠 |

**推奨**: 予算重視なら「WORDRIA／ワードリア」二段併記を1件。
しっかり守るなら「ワードリア」と「WORDRIA」を2件。
アプリのタイトル表記がアルファベット主体（OP動画のロゴが WORDRIA）なので、1件だけに絞るなら
`WORDRIA` 側を優先してもよい。

## 2. 区分と指定商品・役務

### 第9類 — アプリ本体（ダウンロードされるプログラム・コンテンツ）

```
電子計算機用プログラム，家庭用テレビゲーム機用プログラム，
携帯用液晶画面ゲーム機用のプログラムを記憶させた電子回路及びＣＤ－ＲＯＭ，電子出版物
```

- `電子計算機用プログラム` — スマホアプリのプログラム本体はここ。**必須**
- `家庭用テレビゲーム機用プログラム` — 将来の Switch 等への展開用。今やらないなら外す
- `携帯用液晶画面ゲーム機用の…` — 同上
- `電子出版物` — 単語集・学習コンテンツを電子書籍として出すなら

### 第41類 — サービスとしての提供

```
オンラインによるゲームの提供，技芸・スポーツ又は知識の教授，
電子出版物の提供，セミナーの企画・運営又は開催
```

- `オンラインによるゲームの提供` — サーバー経由でゲームを遊ばせる部分。**必須**
- `技芸・スポーツ又は知識の教授` — 語学の教授を含む包括表示。学習アプリなので**推奨**
- `電子出版物の提供` — ダウンロードさせず読ませる形式
- `セミナーの企画・運営又は開催` — 将来リアル講座をやるなら

> 注意: 「ゲームプログラムの提供」という書き方は41類でも42類でも認められません。
> ダウンロードさせるプログラムは9類、遊ばせるサービスは41類、と切り分けます。

### 第42類 — 任意（SaaS・受託開発をやる場合のみ）

```
電子計算機用プログラムの提供，電子計算機用プログラムの設計・作成又は保守
```

アプリを配布するだけなら不要。**まずは 9類＋41類の2区分で十分。**

## 3. 早期審査を狙うなら「広く取りすぎない」

ここがトレードオフです。

| 戦略 | 指定商品・役務 | 審査期間 | 向き |
|---|---|---|---|
| **絞る**（早期審査狙い） | 9類「電子計算機用プログラム」／41類「オンラインによるゲームの提供」「技芸・スポーツ又は知識の教授」 | 約2ヶ月 | 今すぐ権利が欲しい。App Store で既に使っている |
| **広く取る** | §2 のフルセット | 7〜12ヶ月 | 将来の展開まで押さえたい |

早期審査の**対象(2)**は「既に使用している／使用準備を相当程度進めている商品・役務**のみ**を指定している出願」です。
まだ出していない家庭用ゲーム機版やセミナーを入れると、この条件から外れます。

**推奨: 絞って早期審査で1件目を取る。展開が決まった時点で2件目を出す。**
商標は後から追加出願できます。最初の1件で全部を抱え込む必要はありません。

## 4. 費用（特許庁への印紙代、2026年時点）

| | 1区分 | 2区分 | 3区分 |
|---|---|---|---|
| 出願料（3,400＋8,600×区分） | 12,000円 | 20,600円 | 29,200円 |
| 登録料 10年一括（32,900×区分） | 32,900円 | 65,800円 | 98,700円 |
| **合計** | **44,900円** | **86,400円** | **127,900円** |

- 登録料は5年ごとの分割納付（17,200円×区分）も可
- 早期審査の申請手数料は **無料**
- 紙で出願する場合は別途「電子化手数料」1,200円＋700円×枚数
- 商標2件（ワードリア／WORDRIA）出すなら上表の2倍

## 5. J-PlatPat での事前調査手順

https://www.j-platpat.inpit.go.jp/ （無料・登録不要）

### 5-1. 先行商標の調査

1. 上部メニュー「商標」→「商標検索」
2. **検索方式を「称呼（読み方）」にする**（文字の一致より読みの類似が重要）
3. 検索キーワードに `ワードリア` と入力
4. 「区分」に `9` と `41` を入れて絞る
5. ヒットしたものの「ステータス」を見る（登録／出願中／消滅）

**似た読みも必ず見る**（審査官は読みの近さで判断します）:

```
ワードリア／ワードリアル／ワールドリア／ワードリー／ワードピア／ワードリウム
```

さらに、前方一致で `ワード` を9類・41類で検索すると、「ワード◯◯」系がどれだけ混み合っているか分かります。
学習アプリ系は「ワード」が付く商標が多いので、ここは丁寧に。

**判断の目安**: 9類または41類に、読みが同一・近似の**登録**商標があれば、そのままでは通りません。
この場合は弁理士に相談を（回避案があることも多い）。

### 5-2. 指定商品・役務の文言照合

1. 上部メニュー「商標」→「商品・役務名検索」
2. §2 の文言を**1つずつ**貼り付けて検索
3. 完全一致でヒットし、区分が意図どおりか確認する
4. ヒットしない文言は、審査基準外の表示なので**使わない**（似た標準表示に置き換える）

この照合をやっておくと、早期審査の対象(3)にも乗ります。

## 6. 出願方法（4ルート）

| 方法 | 追加費用の目安 | 備考 |
|---|---|---|
| 自分で電子出願 | 0円 | 「インターネット出願ソフト」＋電子証明書（マイナンバーカード可）の準備が必要 |
| 自分で紙出願 | 電子化手数料 1,200円＋700円×枚数 | 同梱の願書テンプレートを使う。特許印紙を貼って郵送 |
| オンライン商標サービス（Cotobox、Toreru 等） | 1〜3万円/区分程度 | 調査〜出願が画面で完結。弁理士付きプランあり |
| 弁理士に依頼 | 5〜10万円/件程度 | 区分選び・拒絶対応まで任せる |

**初めての1〜2区分なら、オンライン商標サービスが費用と手間のバランスで有利。**
紙出願も難しくはないので、費用を抑えたいなら同梱テンプレートで自力も十分可能です。

## 8. 注意点

- **TOEIC は ETS（Educational Testing Service）の登録商標です。**
  リポジトリ名が `toeic_quest` ですが、アプリ名・ストア説明文での TOEIC の使い方には
  ETS のガイドライン上の制約があります。**指定商品・役務の文言にも「TOEIC」は入れないこと。**
- **® は登録後のみ**使用可。出願中〜登録前は ™ にとどめる。
- **先願主義**（早い者勝ち）。使用実績がなくても出願できるので、名前を決めたら早めに出す。
- 登録後**3年間使わない**と、第三者から不使用取消審判を起こされる可能性がある。
  App Store の掲載画面・リリース日のスクショは、日付が分かる形で保存しておく。
- App Store の表示名と登録商標の表記を揃えておくと、後で権利主張しやすい。
