## 進め方

1. J-PlatPat で「出願中」の先願も9類・41類に無いか確認する
2. 指定商品・役務の3つを J-PlatPat「商品・役務名検索」で完全一致照合する
3. 出願ルートを決める（オンライン商標サービス推奨）
4. 願書を提出する
5. 出願番号が出たら早期審査の事情説明書を提出する
6. 登録査定が来たら **30日以内**に登録料を納付する（期限厳守）

詳細はすべて `WORDRIA_商標出願メモ.md` にあります。

- **TOEIC は ETS の登録商標**です。指定商品・役務の文言には入れないこと
- 出願後、商標そのものの変更はできません。指定商品・役務も減らす補正のみ可
