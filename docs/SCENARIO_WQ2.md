## 9. 実装メモ（イベントデータ化の指針）

- 本書の `▼` 区切り1ブロック＝ `ev.text` / `ev.pre` / `ev.after` 配列の1要素。改行 `\n` は実装時に整形
- 章進行フラグ案: `ch1_noizel_down` → `howl_down` → `gag_down` → `blank_down` → `erase_down` → `mutos_down`、仲間加入 `join_gai / join_rina / join_mia`、船 `ship`、サブイベント `sub_recipe / sub_hana / sub_books / sub_dog / sub_dict`
- NPCのセリフ分岐は 1作目の `kingTalk()` と同様に該当フラグで if 分岐（表の「撃破後」列）
- 声を失った住民の共通演出: セリフ中の `……` と（）の地の文で表現。フラグ回復後に「こえが　もどった」バリアントへ差し替え
- 四天王の残留思念（終章）は `type:"npc"` ＋ 回復処理付きの特殊NPCとして実装（しおり石と同処理を流用可）
- 呪文名は1作目の「ファイア６００」「ヒール５００」方式（属性＋TOEICレベル数値）を続投。上位例: 「ストーム７００」「フレア８００」「サンクチュア６００（全体回復）」——いずれも一般語であり固有IP名は使用しない
```
