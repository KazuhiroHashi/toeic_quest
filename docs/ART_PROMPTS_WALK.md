# 歩行アニメ用スプライトの生成依頼（GPT-image用）

今は静止画1枚を上下に揺らして歩きを表現しているため不自然です。
**「歩いている途中の姿（中割り）」をもう1枚ずつ**用意すると、
2コマの歩行アニメになり自然に歩きます。

- アップ先: https://github.com/KazuhiroHashi/toeic_quest/upload/claude/toeic-quest-game-8zva6k/assets/field
- **既存の hero_down.png / hero_up.png / hero_side.png と同じキャラ・同じ画風・同じ大きさ**で、
  「片足を踏み出した歩行ポーズ」を描いてください。ファイル名は末尾に `_b` を付けます。
- 背景は完全に透過。3枚だけです。緑の「Commit changes」を忘れずに。

コツ: 既に作った hero_down.png などを**同じ会話にアップロードして**「この勇者が
歩いている途中（片足を前に出した中割り）の姿を、同じ画風・同じ体格・背景透過で描いて」と
頼むと、同じキャラで揃います。

```
2.5頭身のかわいいデフォルメの勇者（青いマント・学生風の制服・大きな鉛筆の剣）が、
正面を向いて「歩いている途中」の姿を1枚描いてください。片足を前に踏み出し、
反対の腕を軽く振ったウォークポーズ。既存の立ち絵と同じ画風・同じ体格・同じ塗り。
背景は完全に透過。手描き風の油彩タッチ。文字なし。
【保存名: hero_down_b.png】
```

```
同じ勇者を、真後ろ（背中）を向いて「歩いている途中」の姿で1枚描いてください。
片足を前に踏み出したウォークポーズ。既存の後ろ姿と同じ画風・体格・塗り。
背景は完全に透過。文字なし。
【保存名: hero_up_b.png】
```

```
同じ勇者を、右向きの真横で「歩いている途中」の姿で1枚描いてください。
片足を前、反対の足を後ろに引いた分かりやすいウォークポーズ。
既存の横向きと同じ画風・体格・塗り。背景は完全に透過。文字なし。
【保存名: hero_side_b.png】
```

## 実装状況

- ゲーム側は対応済みです。この3枚をアップすると、歩行中に「立ち→踏み出し→立ち」の
  2コマアニメで歩くようになります（左向きは横向きを自動反転）。
- 無い間は、揺れを抑えた控えめな上下動のみになります（横揺れは廃止しました）。
- 余裕があれば、仲間3人（ガイ/リナ/ミア）のフィールド歩行スプライトと、その `_b` も
  同様に作れますが、まずは勇者の3枚で歩きの自然さを確認するのがおすすめです。
