# WORD QUEST II シナリオ C案 「こえの かえる せかい」

> ライバル脚本チームC 提出稿。方針: **「物語が そのまま 遊びになる」**。
> すべてのシナリオギミックは必ずゲームメカニクス（UI・戦闘・BGM・セーブ・マップ）に落とす。
> 四天王を倒すたび、プレイヤーは「世界が回復する手応え」を**画面と手元で**体感する。
> 固有名詞はすべてオリジナル。セリフはドラクエ風かな書き（漢字最小限・分かち書き）。

---

# 0. コンセプト: 「封印」は説明しない。遊ばせる。

沈黙王ミュートスの四天王は「聞く・話す・読む・書く」を封印している。
本案の核は、**封印を4つの異なる「ゲーム上の不便」として実装する**こと。

- 聞く封印 … **NPCの会話が歯抜けの「？？？」になる**／BGMがこもる／敵の大技の予兆が読めない
- 話す封印 … **NPCが一切しゃべれず身ぶり表示になる**／リナの呪文コマンドが封印される
- 読む封印 … **看板・本・アイテム説明が「▓▓▓」に文字化け**／クイズ4択の1つが化ける
- 書く封印 … **その地方では「ぼうけんのきろく」（セーブ）が書けない**／地図の踏破記録がつかない

四天王を倒した瞬間、その不便が**全部いっぺんに直る**。
同じNPCに話しかけると完全版の会話になり、BGMが晴れ、封印中は取れなかった宝・受けられなかった
クエストが解放される。「世界を救う」を、テキストではなく**差分**で語る。
