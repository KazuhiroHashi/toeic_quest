# フィールド刷新用 画像生成ガイド（GPT-image用）

フィールドの見た目を「打ち込み四角タイル＋絵文字」から、戦闘画面と同じ水準の
手描き2Dアートに差し替えるための生成リストです。

- 生成先: ChatGPT（GPT-image）にコードブロックを丸ごと貼り付け
- アップロード先: https://github.com/KazuhiroHashi/toeic_quest/upload/claude/toeic-quest-game-8zva6k/assets/field
  （フォルダが無ければ URL を開いてそのままアップすれば自動で作られます。
  　**緑の「Commit changes」を必ず押してください**）
- ファイル名は各ブロック内の【保存名】の通りにしてください（拡張子 .png）
- 一度に上げるのは 10枚前後ずつが安全です

画像が揃い次第、こちらでフィールド描画エンジンを新規実装して差し替えます
（地形テクスチャ描画・建物アイコン・主人公/NPCスプライト・ボスは既存の敵イラストを流用）。

## バッチ3: 主人公スプライト（3枚・背景透過）

3方向だけでOKです（左右はプログラム側で反転して使います）。
**3枚とも同じキャラクター**に見えることが大事なので、1枚目を作ったあと
同じ会話の中で「同じキャラクターの後ろ姿」「同じキャラクターの横向き」と頼むのがおすすめです。

```
2DファンタジーRPGのフィールド用キャラクタースプライトを1枚描いてください。
2.5頭身のかわいいデフォルメ。手描き風の油彩タッチで、明るく鮮やかな色。
背景は完全に透過。キャラクター1人だけを中央に大きく。文字・ロゴは入れないでください。
題材: 若い勇者。緑の帽子ではなく、青いマントと学生風の制服を着て、
腰に「大きな鉛筆の剣」を差した英語学習の勇者。正面を向いて立っている。
【保存名: hero_down.png】
```

```
（同じ会話の中で続けて）
同じキャラクターをそのままに、真後ろから見た後ろ姿を描いてください。
背景は完全に透過。他の条件は同じです。
【保存名: hero_up.png】
```

```
（同じ会話の中で続けて）
```

## 生成不要のもの

- フィールド上のボス（将軍・ドラゴン・魔王）: 既存の敵イラスト（assets/enemies/）を
  縮小してフィールドに表示するよう実装します。追加生成は不要です。
- 階段・扉など細かいパーツ: プログラム側で描画を改善します。
