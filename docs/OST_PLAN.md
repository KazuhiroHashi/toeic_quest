# サウンドトラック集（BGM集）

2026-09-19。**実装済み。** 設計を検討した経緯と、決めたことの理由を残す。

---

## 仕様（本人決定）

- **通常の冒険を5回クリア、または プレミアム で解放**
- **12曲。曲名は本人が命名**
- ストーリーモードの4曲は**入れない**
- 聴けるだけ。**書き出し・ダウンロードは付けない**

> ⚠️ **プレミアムでの解放は、一度「しない」と決めてから覆した（2026-09-19）。**
> 当初は「5回クリアのご褒美という筋と、お金を払ったご褒美という筋が混ざると
> どちらの意味も薄くなる」として入れない判断をした。
> **本人がプレミアムの価値を厚くするほうに倒した。** 商売の判断なのでそれに従う。
>
> そのぶん、**プレミアムの人には5回クリア時の「解放されました」を出さない。**
> もう聴けているのに「解放された」と言われると嘘になる。

## 解放までの見せ方

| クリア回数 | タイトルの項目 | 押すと |
|---|---|---|
| 0回 | **出ない**（存在も伏せる） | — |
| 1〜4回 | 🔒 サウンドトラック（1／5） | **鍵つきの画面**（下） |
| 5回〜 | ♫ サウンドトラック | 聴ける |
| プレミアム | ♫ サウンドトラック | 回数に関係なく聴ける |

### 初回クリアで、鍵つきの画面を一度だけ見せる

エンディングを見てタイトルに戻ったところで、**サウンドトラックの画面そのものを
開く**（`ostTease`）。プレミアムの人には出さない。

**文字で「5回クリアで解放されます」と言うより、何が待っているかを見せるほうが
伝わる。** 絵も曲名も見えるが、行は薄く、時間の代わりに🔒が出て押せない。
窪みは `LOCKED`。操作盤は出さない。

```
冒険を 5回 クリアすると 解放されます。（現在 1 ／ 5）
プレミアムなら、いますぐ 聴けます。
```

### 5回目のクリアで伝える（プレミアムでない人だけ）

エンディングの終盤に一度だけ挟む。

```
🎵　サウンドトラック集が 解放されました！
```

## 見た目（2026-09-19 作り直し）

本人が用意した2枚の絵を土台にした全画面の画面。
以前はリストだけの小さなパネルだったが、「ダサすぎる」という指摘で組み直した。

| 素材 | 元 | 配信ビルド |
|---|---|---|
| `assets/ui/ost_bg.png` | 941×1672 | `ost_bg.webp` 233KB |
| `assets/ui/ost_frame.png` | 1086×1303（下の透明部分を切り落とした） | `ost_frame.webp` 311KB |

```
  ‹    S O U N D T R A C K
       MUSIC LIVES IN MEMORIES

          ┌──────┐
          │ 金の枠 │  ← 絵。中の窪みに生きた文字を重ねる
          │ NOW  │     twin dragon
          │PLAYING│    ▬▬●────  0:42 / 5:08
          └──────┘

  ♫ TRACK LIST ─────────────
   01 [絵] battle1        2:47
   ...
   ── THE FOUR GENERALS ──
   06 [絵] Howl           1:20

        ⏮   ⏹   ⏭
```

### ★ 枠の絵には見本の文字が焼き込まれている

`ost_frame.png` には `Main Theme - Dawn of Adventure` という**見本の曲名と
再生位置が絵として入っている。** そのままでは使えない。

**窪みの部分に不透明の板をぴったり重ねて隠し、上に生きた文字を描いている。**
板の位置は枠の絵に対する割合で指定してあるので、**枠を大きくしても小さくしても
ずれない。**

```css
.ost-plaque { left: 21.6%; top: 65.0%; width: 56.5%; height: 19.4%; }
```

> この数字は枠の絵を実測して出した。**絵を差し替えたら測り直すこと。**

### 十字キーとA/Bは隠す

この画面では使わないので、開いている間だけ `#controls` を隠す。
閉じるときに元の指定へ戻す。

**隠すと `#screen` が下まで伸びる**（`#screen` は `flex: 1`）。
そのぶん枠も曲目表も大きく取れて、**全12曲が1画面に収まる。**

> 閉じる口は左上の `‹` と Escape。**B ボタンでは閉じられない**（隠れているので）。
> B の受け口は残してあるが、届かない。

### 書体

**2つ埋め込んでいる。どちらも SIL Open Font License 1.1（商用可・埋め込み可）。**
ライセンス本文は `assets/fonts/*-OFL.txt`。

| 書体 | 使いどころ | 大きさ |
|---|---|---|
| **Cinzel** | SOUNDTRACK / TRACK LIST / 番号 / 時間 | 25KB |
| **EB Garamond** | 曲名（battle1 / twin dragon / Howl） | 43KB |

> ★ **なぜ2つ要るのか。Cinzel は大文字しか持たない。**
> 見出しには合うが、曲名に使うと `battle1` が `BATTLE1` になり、
> **本人が付けた綴りが変わってしまう。** 実際に一度そうなった。
>
> ★ **なぜ base64 で CSS に埋め込むのか。**
> アプリはオフラインで動く。Google Fonts の CDN を見に行くと、
> 機内モードや電波の無いところで書体が化ける。ファイルで置く手もあるが、
> `build_www.js` のパス書き換えは CSS には効かないので、
> **パスを持たせないのがいちばん確実。**

和文（BGMがオフのときの案内）は明朝の実装系フォントに任せている
（`Hiragino Mincho ProN` → `Yu Mincho` → `Noto Serif JP`）。埋め込まない。
仮名まで入れると数MBになる。

### 窪みは狭い。和文を入れない

枠の中の窪みは横幅が 100px ほどしかない。**和文を入れると切れる。**
一度「TRACK を えらんでください」と入れて `TRACK を えら…` になった。

- 窪みに出すのは**欧文の短いラベルだけ**（`SELECT TRACK` / `BGM OFF`）
- 和文の案内は、**曲目表の上に横幅いっぱい**で出す

### 送り・停止

参照画像の操作盤に寄せた。**金の枠を回した台**に丸いボタンを3つ。
真ん中だけ大きく、**二重の輪**にして押すところだと分かるようにしてある。
台の左右には小さな金の菱形。

`◀◀` `▶/■` `▶▶`。`bgm.js` には一時停止が無いので、**止めると頭出しになる。**

> 記号は `⏮ ⏭` ではなく `◀◀ ▶▶` にした。前者は端末によって絵文字として
> 描かれ、色や大きさが揃わない。三角なら文字として描かれる。

参照画像にあったシャッフル・リピート・音量つまみは入れていない。

- 音量 … **iOS は `<audio>` の volume を受け付けない**（下の「弱点」）
- リピート … `BGM.play()` は元々ループする。切る手段が無い
- シャッフル … 12曲なので、指で選ぶほうが早い

### 章の区切り

`OST` の項目に `s:` があると、その行の上に区切りが入る。いまは1か所だけ。

```
05  twin dragon
── THE FOUR GENERALS ──
06  Howl
```

細い金の線を左右に流し、中央に小さく組の名前を置いている。

> **四天王＝The Four Generals** にした理由。
> 直訳は `The Four Heavenly Kings`（仏教の四天王の英訳）。
> `The Elite Four` はポケモンの公式訳で一発で通じるが、
> **他社の看板を借りた印象になる**ので避けた。
> `The Four Generals` は字面が短く、Howl / Gag / Brank / Iraze と並べても重くない。

## ★ 四天王の名前の綴り（勝手に直さないこと）

奪う力と、英語の語をかけてある。

| 曲名 | 日本語 | 元の語 | 奪う力 |
|---|---|---|---|
| **Howl** | ハウル | howl（吠える） | 聞く |
| **Gag** | ガグ | gag（口をふさぐ） | 話す |
| **Brank** | ブランク | blank（空白） | 読む |
| **Iraze** | イレイズ | erase（消す） | 書く |

`Brank` `Iraze` は固有名詞として意図的に崩してある。**直さないこと。**

> 2026-09-19、**私が `Haul` と書いて本人に直された。**
> `haul` は「引きずる・運ぶ」という実在の別語で、ハウルの台詞
> （『お前たちの**叫び**は 誰にも届かん！』）と噛み合わない。
> 英単語アプリなので、**英語に詳しい人ほど気づく。**

**`js/bgm.js` は1行も触っていない。**

## なぜ安く済んだのか

### 曲はすでにアプリに入っている

戦闘中に鳴っているファイルをそのまま指している。
**アプリは1バイトも大きくならない。**

### クリア回数はすでに記録されている

`pmain.js` が冒険の完結時に `rc.clears` を増やしている
（`localStorage` の `wq2_records_v1`）。数え直す必要はなかった。

### 「条件を満たしたら項目が出る」仕組みもあった

「挑戦の塔」が `rc.clears > 0` で同じことをしている。同じ形で書いた。

```js
function ostOpen() { return (loadRec().clears || 0) >= OST_CLEARS; }
```

### ★ `bgm.js` を書き換えずに済んだ

**当初は「ここが本丸。中〜大」と見積もっていた。調べ直したら不要だった。**

12曲はすべて `bgm.js` の `TRACKS` に載っている名前で、`BGM.play(name)` を
そのまま呼べる。しかも12曲とも `NO_RESUME` に入っているので、
**呼ぶたびに頭から鳴る。** ギャラリーとして欲しい動きがそのまま出た。

これが効いたのは、`bgm.js` が実機で何度も焼かれている場所だから。
「タップのたびに戦闘曲が鳴り直す」も、**まだ直っていない**
「iPhone で効果音が途切れる」も、この周辺で起きている。
**踏まずに済むなら踏まない。**

> 将来「再生位置のバー」「次の曲へ」を付けたくなったら、そのときは
> `bgm.js` に読み取り専用の取得口を足す。**鳴り方を変える改造はしない。**

## やらないと決めたこと

### バックグラウンド再生

画面を消しても鳴り続ける、というのは**サウンドトラック機能に期待される
いちばん自然な動き**だが、入れない。

- iOS … `UIBackgroundModes: audio` の宣言が要る。
  **Apple はこの宣言を厳しく見る。**「本当にバックグラウンド再生が必要な
  アプリか」を審査で問われる。英単語RPGでこれを出すのは、説明が要る
- Android … フォアグラウンドサービスと通知が要る

**どちらも審査と実装の両方で重い。** まず画面を開いている間だけ鳴るもので
出して、要望が来てから考える。

### 曲の書き出し・ダウンロード

Suno Pro で作った曲の商用利用権は本人にあるので法的には可能だが、
書き出しボタンを付けると再配布の話になり、ストアの規約とも絡む。
**聴けるだけ**にしておく。

### ストーリーモードの4曲

`tools/build_www.js` の `SKIP_BGM`（`field` `town` `dungeon` `battle_dungeon`）。
ストーリーモードが制作中なので配信ビルドに入っていない。

入れると曲数は増えるが**アプリが約16MB太る**うえ、
「聴けるのに、その場面がゲームに無い」ことになる。
**ストーリーモードを出すときに足せばよい。**

## 正直に言っておく弱点

### 音が小さい

配信する mp3 は `BGM_GAIN = 0.62` を焼き込んである
（読み上げを聞かせるため 0.73 から下げた。2026-09-09）。

**そして iOS は `<audio>` の `volume` を受け付けない。**
`bgm.js` にもそう書いてある。つまり**ギャラリーだけ音量を上げることはできない。**

サウンドトラックとして聴くには、やや小さい音で鳴る。
端末の音量を上げてもらうしかない。

> 全音量の別ファイルを同梱すれば解決するが、**+45MB。** 割に合わない。
>
> Web Audio に繋げば音量は取れるが、`bgm.js` には
> 「createMediaElementSource に繋いだ要素は src を差し替えても鳴り始めない
> ことがある（WebKitの既知のふるまい）」として**一度撤去した記録がある。**
> **実際に「音が小さい」と言われてから考える。**

### BGM をオフにしていると鳴らない

タイトル右上の 🔊 を切っていると `BGM.play()` は何もしない。
黙って無反応だと「壊れている」と読まれるので、
パネルの下に理由を出すようにした。

```
BGM が オフに なっています（右上の 🔊）
```

### 解放は端末ごと。消える

`wq2_records_v1` は localStorage。**アプリを入れ直すと 0 に戻る。**
クラウド保存の仕組みは無い。

5回クリアした人がそれを失うのは、他の記録（単語帳・称号）も同じなので
この機能だけの問題ではない。**が、「解放」という言葉を使う以上、
失われたときの落胆は大きい。** 頭には置いておく。
