## なぜ安く済んだのか

### 曲はすでにアプリに入っている

戦闘中に鳴っているファイルをそのまま指している。
**アプリは1バイトも大きくならない。**

### クリア回数はすでに記録されている

`pmain.js` が冒険の完結時に `rc.clears` を増やしている
（`localStorage` の `wq2_records_v1`）。数え直す必要はなかった。

### 「条件を満たしたら項目が出る」仕組みもあった

「挑戦の塔」が `rc.clears > 0` で同じことをしている。同じ形で書いた。

```js
function ostOpen() { return (loadRec().clears || 0) >= OST_CLEARS; }
```

### ★ `bgm.js` を書き換えずに済んだ

**当初は「ここが本丸。中〜大」と見積もっていた。調べ直したら不要だった。**

12曲はすべて `bgm.js` の `TRACKS` に載っている名前で、`BGM.play(name)` を
そのまま呼べる。しかも12曲とも `NO_RESUME` に入っているので、
**呼ぶたびに頭から鳴る。** ギャラリーとして欲しい動きがそのまま出た。

これが効いたのは、`bgm.js` が実機で何度も焼かれている場所だから。
「タップのたびに戦闘曲が鳴り直す」も、**まだ直っていない**
「iPhone で効果音が途切れる」も、この周辺で起きている。
**踏まずに済むなら踏まない。**

> 将来「再生位置のバー」「次の曲へ」を付けたくなったら、そのときは
> `bgm.js` に読み取り専用の取得口を足す。**鳴り方を変える改造はしない。**

## やらないと決めたこと

### バックグラウンド再生

画面を消しても鳴り続ける、というのは**サウンドトラック機能に期待される
いちばん自然な動き**だが、入れない。

- iOS … `UIBackgroundModes: audio` の宣言が要る。
  **Apple はこの宣言を厳しく見る。**「本当にバックグラウンド再生が必要な
  アプリか」を審査で問われる。英単語RPGでこれを出すのは、説明が要る
- Android … フォアグラウンドサービスと通知が要る

**どちらも審査と実装の両方で重い。** まず画面を開いている間だけ鳴るもので
出して、要望が来てから考える。

### 曲の書き出し・ダウンロード

Suno Pro で作った曲の商用利用権は本人にあるので法的には可能だが、
書き出しボタンを付けると再配布の話になり、ストアの規約とも絡む。
**聴けるだけ**にしておく。

### ストーリーモードの4曲

`tools/build_www.js` の `SKIP_BGM`（`field` `town` `dungeon` `battle_dungeon`）。
ストーリーモードが制作中なので配信ビルドに入っていない。

入れると曲数は増えるが**アプリが約16MB太る**うえ、
「聴けるのに、その場面がゲームに無い」ことになる。
**ストーリーモードを出すときに足せばよい。**

## 正直に言っておく弱点

### 音が小さい

配信する mp3 は `BGM_GAIN = 0.62` を焼き込んである
（読み上げを聞かせるため 0.73 から下げた。2026-09-09）。

**そして iOS は `<audio>` の `volume` を受け付けない。**
`bgm.js` にもそう書いてある。つまり**ギャラリーだけ音量を上げることはできない。**

サウンドトラックとして聴くには、やや小さい音で鳴る。
端末の音量を上げてもらうしかない。

> 全音量の別ファイルを同梱すれば解決するが、**+45MB。** 割に合わない。
>
> Web Audio に繋げば音量は取れるが、`bgm.js` には
> 「createMediaElementSource に繋いだ要素は src を差し替えても鳴り始めない
> ことがある（WebKitの既知のふるまい）」として**一度撤去した記録がある。**
> **実際に「音が小さい」と言われてから考える。**

### BGM をオフにしていると鳴らない

タイトル右上の 🔊 を切っていると `BGM.play()` は何もしない。
黙って無反応だと「壊れている」と読まれるので、
パネルの下に理由を出すようにした。

```
BGM が オフに なっています（右上の 🔊）
```

### 解放は端末ごと。消える

`wq2_records_v1` は localStorage。**アプリを入れ直すと 0 に戻る。**
クラウド保存の仕組みは無い。

5回クリアした人がそれを失うのは、他の記録（単語帳・称号）も同じなので
この機能だけの問題ではない。**が、「解放」という言葉を使う以上、
失われたときの落胆は大きい。** 頭には置いておく。
