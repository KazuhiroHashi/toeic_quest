## C. AAB を作ってアップロードする（Mac・60分）

⚠️ **ここだけは Mac が要ります。** Capacitor 8 に上げたので、
`android/` フォルダは作り直しになります。

詳細は `docs/CAPACITOR8_MIGRATION.md`。要点だけ：

```bash
cd ~/toeic_quest
git pull origin claude/toeic-quest-game-8zva6k

node -v                 # v22 以上であること。低ければ brew upgrade node

rm -rf node_modules android ios
npm install

npm run build:www
npx cap add android
npm run assets          # アイコンとスプラッシュ（cap add のあと）
npm run cap:sync        # ← ここが要
npx cap open android
```

> **`npm run cap:sync` を `npx cap sync` で代用しないこと。**
> AdMob のアプリIDが AndroidManifest.xml に入らず、**広告が一切出なくなります。**

Android Studio が開いたら：

1. Gradle sync が走る（初回10分ほど）
2. **Build → Generate Signed Bundle / APK → Android App Bundle**
3. **署名鍵（.jks）はこれまでのものを使う。新しく作り直さないこと**
4. できた `.aab` を Play Console の「**製品版**」→「**新しいリリースを作成**」でアップロード

Android Studio が「この AGP はサポートされていません」と言ったら、
Android Studio 自体を更新してください（Ladybug 以降が要ります）。

## 公開されたあとにやること（忘れやすい）

- **AdMob のアプリを Google Play のストア掲載情報に紐づける**
  → いま マッチ率 0.00%（広告が一度も出ていない）のは、
    「ストア情報が未登録のアプリには広告配信を制限する」という
    AdMob の仕様のためです。**バグではありません。公開が先です**
- `app-ads.txt` を `bridge-ai-tokyo.com` に置く
- `bridge-ai-tokyo.com/wordria/` の紹介ページを作る
  （いまは privacy.html と terms.html しか無く、`/wordria/` は404）
- `/wordquest/` をリダイレクトに変える
  **※ストアが `/wordria/` を向き、アプリが公開されるまでは消さないこと**
