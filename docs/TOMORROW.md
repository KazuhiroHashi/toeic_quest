## B. 申告の残り ✅ 済（2026-09-13）

**場所**：左メニュー「**モニタリングと改善**」→「**ポリシーとプログラム**」
→「**アプリのコンテンツ**」

> 手順書には「左メニュー『ポリシーとプログラム』」とだけ書いてあったが、
> 実際は「モニタリングと改善」の中。ダッシュボードの「タスクを表示する」は
> クローズドテストの手順で、申告項目はそこには出ない。

**実際に残っていたのは ⑩ 広告 ID だけだった。** ⑦⑧⑨ は済んでいた。

| 項目 | 答え |
|---|---|
| **行政機関のアプリ** | **いいえ** |
| **金融取引機能** | **いいえ** |
| **健康アプリ** | **いいえ** |
| **広告 ID** | **はい** → 目的は「**広告、マーケティング**」**1つだけ** |

> **広告 ID だけ「はい」。** AdMob が広告 ID を使うため。
> ここを「いいえ」にすると申告と中身が食い違い、公開停止の理由になる。

**目的のチェックは「広告、マーケティング」1つだけ。** データセーフティでは
分析と不正行為防止にもチェックを入れたので紛らわしいが、聞かれていることが違う。

- データ セーフティ … 集めた**データ全体**を何に使うか（AdMob は分析にも不正検知にも使う）
- この画面 … **広告 ID そのもの**を何のために必要としているか

このアプリが広告 ID を要るのは広告を出すためだけ。解析ツールは1つも入って
いない（Firebase / Analytics / Crashlytics なし）。自前の不正検知もしていない。

**「カスタマイズ」には絶対にチェックを入れないこと。** 非パーソナライズ広告
（`npa: true`）で動かしており、Apple にも「追跡しない」と申告してある。

## D. Mac で AAB を作る（60分）

**AAB とは：アプリ本体のファイル**（Android App Bundle・拡張子 `.aab`）。
2021年から Google Play は新規アプリにこの形式を要求しています。

Capacitor 8 に上げたので、`android/` フォルダは作り直しになります。
詳細は `docs/CAPACITOR8_MIGRATION.md`。

**▼ Terminal に貼る（1行ずつ）**

```bash
cd ~/toeic_quest
git pull origin claude/toeic-quest-game-8zva6k
node -v                 # v22 以上であること。低ければ brew upgrade node
rm -rf node_modules android ios
npm install
npm run build:www
npx cap add android
npm run assets
npm run cap:sync
npx cap open android
```

> **`npm run cap:sync` を `npx cap sync` で代用しないこと。**
> AdMob のアプリIDが AndroidManifest.xml に入らず、**広告が一切出なくなります。**

Android Studio が開いたら：

1. Gradle sync が走る（初回10分ほど）
2. **Build → Generate Signed Bundle / APK → Android App Bundle**
3. **署名鍵（.jks）はこれまでのものを使う。**
   **作り直すと、以後このアプリを更新できなくなります**
4. `.aab` ファイルができる

「この AGP はサポートされていません」と出たら、Android Studio 自体を
更新してください（Ladybug 以降が必要）。

### ⚠️ ビルドしたら、AD_ID 権限が入っているか確かめる

⑩ 広告 ID を「**はい**」で申告した（2026-09-13）。この申告をすると、
**`com.google.android.gms.permission.AD_ID` 権限が入っていないビルドは
アップロードがブロックされる**（Android 13 以降をターゲットにする場合）。

この権限は `@capacitor-community/admob` 自身の AndroidManifest には
書かれていない。**Google Mobile Ads SDK（play-services-ads 20.4.0 以降）の
AAR が持っていて、マニフェストの結合で自動的に入る**仕組み。
このプロジェクトは `25.4.+` を使うので条件は満たしている。

ただし自動なので、入っていることを一度は目で見ておく。
`npx cap open android` でビルドが通ったあと、Terminal で：

```bash
grep -rl "permission.AD_ID" android/app/build/intermediates/ | head
```

何か出れば入っている。**何も出ないときはアップロードする前に相談すること。**
Android Studio で `AndroidManifest.xml` を開き、下の
「**Merged Manifest**」タブを見ても同じことが確かめられる。

### エンディングのムービーが3人（パーティは4人）

ED は3カットのつなぎで、**仲間が映るのは ED-3「旅の続き」だけ**。
そこに歩いているのが**3人**になっている。ミアは4戦目のあとに加わるので、
エンディング時点のパーティは4人。食い違っている。

**原因は指示漏れ。** `docs/MOVIE_PROMPTS.md` の ED-3 のプロンプトが

```
Tiny hero silhouettes walk together down a path toward the horizon.
```

と書いてあるだけで、**人数を指定していない**。Seedance が3人にした。

**直し方**（Higgsfield ＋ Seedance 2.5・9:16・10秒・音声なし）

起点画像 `assets/bg/zone4.png` は変えず、その1行をこうする。

```
Exactly four tiny hero silhouettes walk together down a path toward
the horizon — a boy with a sword and cape, an armored warrior,
a girl in a pointed witch hat, and a girl in white robes.
```

そのあと `movie/src/ed3.mp4` を差し替えて `node tools/build_movie.js`。

**ついでに直ること：** いまは `movie/cuts.json` で
「6秒手前から崩れた文字が空に出るため、その前で切る」として
**10秒撮ったうち5.4秒しか使っていない**。共通スタイル指定の
「文字を出さない」（ED-3 は文字なしのカット）は整理済みなので、
撮り直せば10秒フルで使えるかもしれない。

> ムービーの差し替えは AAB のビルドと独立していて、**公開後の
> アップデートでも直せる**。ストアを先に片づけてよい。

### ~~BGM のループの継ぎ目~~ → 出荷分は済（2026-09-13）

**何のことか。** Suno は曲の最後を必ずフェードアウトさせる。ところが
アプリは `<audio loop>` で鳴らすので、**音が消えたあと、いきなり頭から
鳴り直す**。「スーッと消えて、ドン」と聞こえる、あれのこと。
`tools/loop_bgm.js` がフェードを切り落として、末尾を曲の頭につなぎ直す。

**以前ここに書いてあった10曲の名前は間違っていました。**
`arena1〜4, boss, king2〜4, lastboss, midboss` と書いてありましたが、
測ったらこれらは**すでに処理済み**でした。実際に残っていたのは別の曲です。
数だけ合っていて、中身が入れ替わっていた。

いまの状態は、いつでもこれで確かめられます（何も書き換えません）：

```bash
node tools/loop_bgm.js assets/bgm/*.mp3 --check
```

**出荷ビルドに入る曲は、全部かたづきました。**

| 曲 | 直した | なぜ |
|---|---|---|
| `title` | ✅ 58dB → 3dB | タイトル画面。**全員が必ず聞く**。4分で一周する |
| `ending` | ✅ 73dB → 6dB | エンディング。6dBは曲そのものの静かな終わり方（実測で確認） |
| `gameover` | ✅ 47dB → 0.5dB | 全滅の曲 |

**★が残っている曲は、直さなくてよい。** 理由：

- `field` `town` `dungeon` `battle_dungeon` … 制作中のストーリーモード専用。
  `tools/build_www.js` の `SKIP_BGM` で**出荷ビルドに入っていない**
- `battle` `battle2` … 入ってはいるが、**鳴る場面が無い**。戦闘の曲は
  11曲すべてが `bgm:` で名指しされていて（arena1〜4/king1〜4/boss/midboss/
  lastboss）、この2曲は「名指しが無かったとき」の保険。出番が来ない
- `victory` … 6秒のファンファーレ。**ループしない**ので、
  フェードアウトが正しい。効果音として鳴らしている（`pbattle.js`）

> `battle` と `battle2` を同梱から外せば **5.6MB 減らせます**が、
> 保険を外すことになるので、公開を急ぐいまは触っていません。
