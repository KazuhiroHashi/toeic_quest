# Word Quest PR戦略メモ（Geminiとの壁打ちより）

App Store公開・X（旧Twitter）でのバズを狙うにあたり、Geminiとの相談で得られた「名案」をまとめておく。

## 開発環境・スタック

- **Blender**: 3Dモデリング（アセット制作）。最初はローポリ＋単色ベタ塗りテクスチャで統一感を出す。
- **Unity**: ステージ配置・ライティング・当たり判定・物理挙動などゲームの統合。
- **Claude Code + MCP**: C#スクリプト生成、Unity/Blenderの直接操作（プレハブ生成、パラメータ設定、Pythonスクリプトでの反復作業自動化）。
- **Aqua Voice**: MacBookへの音声入力でClaude Codeに指示。タイピングの壁をなくし、思考速度のまま開発できる。
- **Suno**: BGM生成
- **ElevenLabs**: ボイス・効果音生成
- **GPT Image**: グラフィック生成
- **SeaDance 2.0**: カットシーン等の動画演出

## 開発時の注意点

- **Blender→Unityの座標系ズレ**: BlenderはZ軸上、UnityはY軸上。拡大・回転後は `Ctrl+A`（全トランスフォームを適用）してから `.fbx` で書き出すか、`.blend` を直接配置する。
- **AIコードのブラックボックス化対策**: 「このコードの仕組みを中学生向けに1行ずつコメントで解説して」とClaudeに聞く習慣をつける。
- **スコープ肥大化の防止**: 最初から壮大なゲームを狙わず、「5分で遊べるミニゲーム」を1本完成させることを優先する。
- **バージョン管理**: 大きな変更前は `git commit`。AIに大規模な書き換えを頼む時は「実行前に変更内容を教えて」とワンクッション置く。

## 『Word Quest』について

ドラクエ風の英単語学習RPG。「問題を解く＝敵を倒す・経験値が入る」という構造にすることで、勉強を作業ではなくゲームの快感に変換している。Suno/ElevenLabs/GPT Image/SeaDanceによるリッチな演出で「安っぽい教材アプリ」感を払拭している点が強み。

### 需要がある理由

1. 全国の親が抱える「勉強しない」「ゲームばかり」という共通の悩みに対する解決策になる
2. 大手の総合ドリル型アプリと違い、「特定分野に絞った尖ったテーマ」のニッチなゲームは刺さりやすい
3. 身近に本物のユーザー（子ども）がいて、リアルなフィードバックを得ながら改善できる

### 商標・審査対策（App Store公開前チェック）

- 「ドラクエ」という単語や実際の呪文名（ホイミ、メラ等）はタイトル・説明文・ゲーム内から完全に排除し、オリジナルの名称にする（システムや雰囲気のオマージュに留める）
- 最初は完全無料または買い切りにして審査をスムーズにする

## 娘が3Dゲームを動かしている様子を投稿する案

「中学生の娘がMacBookに音声で指示しながら自作の3Dゲームを動かしている」動画は、Word Quest単体の告知よりもさらに大きなインパクトが期待できる。

- IT・エンジニア層、子育て・教育層、クリエイター層の全方位に刺さる
- 「親がWord Questを作り、その環境で娘自身も3Dゲームを作り始めている」という親子の相乗効果ストーリーが強い

**プライバシー保護の注意点（必須）**

- 顔・制服・部屋の特定要素は映さない（後ろ姿・手元・画面越しのアングルにする）
- 本名・学校名・地域が分かる情報は画面・音声から除く
- 投稿前に本人の同意を必ず取る。本人が嫌がる場合は無理に出さない

## 勉強とゲーム開発をつなげるアイデア（メモ）

- 数学・理科: 3D座標、角度、ベクトル、重力・摩擦・放物線（ジャンプの軌道計算）
- 英語: Unity/Blenderの英語ドキュメント、エラーログ読解
- 国語: AIへ意図を正確に伝えるための主語・述語・条件整理、ストーリー・世界観設定
- 運用: 「宿題を終えたら開発OK」というように、ゲーム制作を勉強のご褒美に位置づける
