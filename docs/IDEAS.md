# 面白さ×継続性 強化アイデア(6視点並列ブレスト統合版)

6つの専門視点(リテンション/学習科学/戦闘/育成収集/ソーシャル/エンドコンテンツ)で
並列ブレストした計60案を統合し、重複を「複数班が独立に提案した=強いシグナル」として評価した。

## 最重要の発見: 4班が独立に同じ答えに到達したアイデアがある

**「ミスした単語が敵として蘇り、倒す(=正解する)ことが復習になる」**
- 学習班1位「よみがえりの魔物」(SRS間隔反復をエンカウントに溶かす)
- 戦闘班1位「リベンジワード」(敵がミス単語を呪いとして使う→正解で無効化+反射)
- エンド班1位「弱点討伐ボスラッシュ」(苦手単語だけのボス連戦、3連続正解で成仏)
- リテンション班「亡霊の再来」

これは本作にしか作れない体験であり、**学習効果(間隔反復)・戦闘の面白さ・毎日開く理由を1つの仕組みで同時に満たす**。最優先で実装すべき。

## 実装ロードマップ(効果×コスト順)

### Phase 1: 戦闘と学習の核を強化(各1日以内・小コスト)
1. **リベンジワード** — 敵がミス単語で攻撃、正解で無効化+カウンター。ミス記録は実装済みなので分岐追加のみ
2. **コンボチェイン** — 連続正解でダメージ倍率(戦闘をまたいで持続)。誤答でリセット。変数1つ+乗算1行
3. **単語図鑑★(銅/銀/金)** — 全アイデアの土台。正解履歴は既にある。図鑑UIとレベル帯別コンプ率
4. **戦闘内リベンジ再出題** — バトル中の誤答語は正解を1.5秒表示→数ターン後に必ず再出題(学習科学の即時修正+再テスト)

### Phase 2: 毎日開く理由を作る(2〜3日)
5. **デイリーダンジョン+絵文字リザルト** — 日付シードで全員同じ10連戦、1日1回。結果を絵文字でシェア
6. **ストリーク聖火** — 既存ログインボーナスを「消えたら惜しい」演出に強化+護符
7. **推定スコア成長グラフ** — つよさ画面に推定TOEIC帯と折れ線、月1で共有カード提案

### Phase 3: 寿命を伸ばす(各3〜5日)
8. **ことばの塔(無限ローグライク)** — クリア後の主力コンテンツ。週替わり異変ルールの土台にもなる
9. **転生システム** — 周回で出題レベル+100&日→英反転。専用称号
10. **ボス多段形態+ラストワード** — ボスHP50%で第2形態。ボス固有の象徴単語でとどめ(単語がエピソード記憶化)

### Phase 4(将来・ネイティブ化後)
- Game Centerランキング(累計討伐語彙数/週間EXP)・実績50種
- みきりカウンター(敵ターンにも防御クイズ)、自信度ベット、音声リスニング出題(洞窟=耳で聞く)
- おともシステム(ノーミス討伐で魔物と契約→連れ歩き)
- ギルド対抗戦(要サーバー)

## 設計上の合意事項(班横断)
- 日本のTOEIC学習者は「努力は見せたいが点数の絶対値は隠したい」→ 共有は絵文字・称号・伸び幅の形式に限定
- 「1日1回だけ」「今週だけ」の希少性がプレイ時間ではなく**起動日数**を最大化する
- 復習(SRS)はプレイヤーに「復習」と言わずゲームの文法(蘇る敵)に翻訳して溶かす
- すべてサーバーレス(日付シード+localStorage)で成立する形から始め、Game Center→サーバーの順に拡張
