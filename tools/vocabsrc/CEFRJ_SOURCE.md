## CEFR-J Grammar Profile Version 20180315

文法事項にレベルを付けたもの。学年の目安を説明するときの裏づけに使う。

## レベルと学年の対応

    A1     → 中1・中2
    A2     → 中3
    B1     → 高校1年（高校基礎）
    B2     → 高校2年（大学入試）
    C1/C2  → 高校3年（難関大）
    未収録  → 判断できないので、元の段のまま置く

CEFR-J のレベルは「日本の何年生で習うか」を直接示すものではない。
学習指導要領は語ごとの学年を定めていないので、これは目安である。
