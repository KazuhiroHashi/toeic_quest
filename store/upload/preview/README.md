# App プレビュー（ストアに出す動画）

App Store Connect の「プレビューとスクリーンショット」に上げる動画を置く。

| ファイル | 中身 |
|---|---|
| `wordquest_pr_886x1920.mp4` | **本番用。** 家族制作のPR動画 |
| `op_preview_886x1920.mp4` | 予備。ゲーム内OPムービーを切り出したもの |

## 条件（外れると App Store Connect が受け付けない）

- 寸法 **886 × 1920**（縦）または 1920 × 886（横）。1080×1920 は弾かれる
- 長さ **15〜30秒**
- 30fps / H.264 + AAC / 500MB以下
- 1つの言語につき最大3本

## 作り方

```
node tools/make_preview.js <元の動画> --start 0 --len 29.5 --fit
```

- `--fit` … 切らずに全体を収め、余白を背景色で埋める
- 付けないと 886:1920 に合わせて端が切り落とされる（何%切れるか実行時に表示される）
- `--shift ±N` … 切る位置を左右にずらす

## 元の動画（原本）の置き場所

`movie/raw/` に置く。ここは `.gitignore` に入れてあるのでコミットされない。
GitHubは1ファイル100MBまでで、撮って出しの動画はすぐ超えるため。
