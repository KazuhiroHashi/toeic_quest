# App プレビュー（ストアに出す動画）

App Store Connect の「プレビューとスクリーンショット」に上げる動画を置く。

| ファイル | 中身 |
|---|---|
| `wordquest_pr_886x1920.mp4` | **本番用。** 家族制作のPR動画。ファイル名は作った当時のまま |
| `op_preview_886x1920.mp4` | 予備。ゲーム内OPムービーを切り出したもの |

## いまの状態（2026-09-16 確認）

| ファイル | ロゴ | 使えるか |
|---|---|---|
| `op_preview_886x1920.mp4` | **WORDRIA** | ✅ そのまま上げられる |
| `wordquest_pr_886x1920.mp4` | **WORD QUEST**（旧） | ❌ 使えない |

`op_preview` は改名後に作り直してあり、末尾のロゴは WORDRIA になっている
（26秒地点で確認）。**以前ここに「どちらの動画も旧ロゴが出る」と書いてあったが、
op_preview については古い記述だった。**

`wordquest_pr` は旧版のまま。ロゴだけでなく、テロップ「WORDQUESTは」、
メニューの「ことばの闘技場」、Aボタンの「話す/決定」まで全部が旧い。
**新しいApp名のまま出すと ガイドライン 2.3.3（実際の画面と一致していること）
に触れる。**

作り直すなら：
- `op_preview` … `node tools/build_movie.js` でOPを組み直したあと、
  `node tools/make_preview.js movie/out/OP.mp4 --fit`
- `wordquest_pr` … 家族制作。作り直しはご本人たちに依頼が要る

## iPad の動画は用意していない（2026-09-19）

**そして必須ではない。** App プレビューは任意で、必須なのはスクリーンショットだけ。

作らないほうがいい理由もある。**OPムービーは 9:16 の縦長**だが、
**iPad のプレビュー枠は 3:4**（1200×1600）。入れると左右に大きな黒帯が出る。
iPad に動画を出すなら、iPad 向けに撮り直すところからになる。

**iPhone だけ動画、iPad はスクリーンショットのみ。** これで問題ない。

> `tools/make_preview.js` は 886×1920 に固定してある（`var W = 886, H = 1920;`）。
> 別の寸法が要るようになったら、そこを引数にすること。

## 条件（外れると App Store Connect が受け付けない）

- 寸法 **886 × 1920**（縦）または 1920 × 886（横）。1080×1920 は弾かれる
- 長さ **15〜30秒**
- 30fps / H.264 + AAC / 500MB以下
- 1つの言語につき最大3本

## 作り方

```
node tools/make_preview.js <元の動画> --start 0 --len 29.5 --fit
```

- `--fit` … 切らずに全体を収め、余白を背景色で埋める
- 付けないと 886:1920 に合わせて端が切り落とされる（何%切れるか実行時に表示される）
- `--shift ±N` … 切る位置を左右にずらす

## 元の動画（原本）の置き場所

`movie/raw/` に置く。ここは `.gitignore` に入れてあるのでコミットされない。
GitHubは1ファイル100MBまでで、撮って出しの動画はすぐ超えるため。
