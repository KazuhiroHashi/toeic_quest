# TOEIC QUEST 〜英単語で魔王を倒せ〜

ドラクエ1風のレトロRPG × TOEIC英単語学習アプリ。
**敵への攻撃 = 英単語クイズ(4択・制限時間5秒)**。正解すれば攻撃ヒット、2秒以内なら会心の一撃、間違えれば空振りして敵の反撃を受ける。

## 遊び方

ビルド不要。`index.html` をブラウザで開くだけで動きます(スマホSafari/Chrome対応・タッチ操作)。

```bash
# ローカルで
open index.html
# またはサーバを立てて
python3 -m http.server 8000   # → http://localhost:8000
```

GitHub Pages を有効にすれば URL 配布でそのままスマホでテストプレイできます。

### 操作
| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面下の十字キー | 矢印キー / WASD |
| はなす・けってい | Ａボタン | Enter / Z |
| メニュー・もどる | Ｂボタン | Esc / X |
| クイズ回答 | 選択肢をタップ | 1〜4 キー |

## ゲーム内容

- **ストーリー**: 魔王ヴォキャブロスに《言葉の力》を奪われたレキシア大陸を救う王道RPG。二人の将軍を倒し、ことばのカギで魔王城へ。
- **戦闘 = 英単語**: 敵の強さ = 単語レベル(TOEIC 400/500/600/700/800/900)。フィールドを進むほど高レベルの単語が出題される。
- **収録語彙**: 6レベル × 500語 = **3000語**(日本語の意味・品詞つき)
- **敵**: 32種(ワードスライム、カンニングゴースト、パートファイブポニー、メタルワード、魔王ヴォキャブロス など)
- **魔法**: 「ファイア６００」「サンダー８００」など、MPを消費し**魔法名の数字レベルの単語**に正解すると発動
- **RPG要素**: 経験値・レベルアップ(最大Lv30)・呪文習得・武器防具屋・宿屋・宝箱・洞窟(暗闇)・塔・魔王城
- **学習機能**: 間違えた単語は出題率アップ(Anki風)。メニューの「たんごちょう」で苦手単語を復習
- **セーブ**: localStorage 自動保存 + 手動セーブ
